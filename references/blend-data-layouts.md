## 复用与边界

`source/expansion30.py` 是独立标准库Python模块，内含本主题配置、数据和SVG渲染函数。`get_slides('en')` 或 `get_slides('zh-CN')` 返回20个完整section；`validate_data()` 验证尺度边界、各组百分比、工时余额、桑基每层与节点守恒、散点与热力格数量等。它不读取 `data-chart-values` 去修改浏览器图形，也不依赖装饰素材库。

在工作副本运行以下命令生成一个**新片段文件**，然后由 Agent 按需要替换 `source/slides.html` 的对应section。已有输出文件会拒绝覆盖；不能直接把片段当成完整演示打开。

```sh
python3 source/expansion30.py --lang zh-CN --output /absolute/path/to/new-layouts.html
```

三个节点层的桑基总量为 `[40,35,25]` → `[60,40]` → `[65,35]`。第一段矩阵 `[[30,10],[20,15],[10,15]]`，第二段 `[[40,20],[25,15]]`，10条全部标值，单位4px/项；流带的透明叠色不编码额外数量。环形图不做透视，漏斗每层等高且宽度精确对应数量，不能把梯形面积误当人数。

排版在全宽图、并列列、左侧大字与图、数值表、流程和矩阵之间变化。四列卡片的文字如增长，先调整行长、字号和数量，不裁掉信息。比较表是维度行与方案列的矩阵；正文长时需要改行高和列宽，不能仅更换词语。

新增20页使用 `.expansion30` 命名空间，标题80px顶距、说明约200px、图框340px×1680×610。原页面CSS和插槽位置不被重排。单位、图例与条件属于信息内容；不为装饰添加数字旁注。

## 柔润材质

第 10 页采用独立圆角卡片与轻微错落的排布。默认卡片使用浅灰紫 #E3E0EB；选中卡片复用第 11 页最后一根柱子的蓝紫材质：相同的横向渐变（#A99BFF、#7665F8、#5D57F4、#4940B7）、左上柔光与内侧亮边，使用白色文字。两页共用 material_defs / material_rect 材质配方，卡片分配独立渐变 ID。左上角统一使用倾斜图钉 SVG 图标，底部分隔线使用 28% 不透明度。样稿强调第三项；`cards(lang, selected=2)` 使用零起始索引，None 表示无选中态；实际生成按内容选择列数、重点和文字长度，重新检查宽度与留白。第 11、12 页的柱条使用同源蜜桃与紫色材质，渐变横跨柱宽或条高，原有数据外轮廓和零基线保持准确。`material_defs(kind)` 与 `material_rect(...)` 保留在配方中；材质组与数据一起入场，保存与导出使用完整静态终态。复用到同页多个图表时，为每组 SVG 定义分配唯一 ID，避免渐变引用冲突。

## 动画与验收

原生SVG为完整静态终态。`draw`只用于实线，虚线用`wipe-x`；柱条按轴展开，流带分阶段出现，等径点以view-box坐标保持中心。所有WAAPI对象交给播放器统一finish/cancel，不写持久隐藏样式。

验收包含中英新增页真实浏览器截图、文字边界与标题间距、数值验证、实际动画开始/中段/结束、快速翻页与关闭动效。保存HTML再离线打开，PDF使用同一份内容与已解析SVG字体，检查静态终态；底部文字编辑不是数据几何编辑器。


## 材质在图表和信息结构中的应用

第13页等量符号、第14／15页横向柱条、第16页瀑布柱、第25页比较矩阵、第26页时间轴节点、第28页环形与第29页四色漏斗统一使用柔润材质。紫、蜜桃、薄荷、浅紫沿用本主题色板，左上柔光和内侧亮边统一；正文区域保留清楚对比。渐变只表达表面，不增加数据含义。定量图形不增加透视、外扩侧面或阴影，保持原宽高、基线、环形角度和数量。堆积条内部不留缝，环形不挤出、不拉椭圆。

第20页保持100项需求、10条流与4px/项的守恒关系，流带加柔和渐变，来源、路径、结果节点分层；数值与名称采用独立上下布局。第21页以等径柔光圆点展示原始数据，背景分区仅依据标注的10小时／60分讨论阈值；用户数据有不同决策标准时必须一起调整阈值、分区、标签和元数据。第27页使用带柔润材质的步骤节点与菱形判断节点，回路明确返回证据整理；可按真实业务增加、减少或重排节点，不固定为七个。

第07／17／18页的实线沿数据路径描画，虚线和面积从左至右显现，点位随横向进度出现。第19页雷达先显现淡填充，再描绘轮廓与顶点。所有动画在约2秒内结束，重复翻页可重播；关闭动效、减少动态、编辑、保存HTML和PDF均回到原生静态终态。预览图库的BLEND大图使用同一份HTML播放，缩略图仍展示静态终态，避免预览与导出出现不同版式。
