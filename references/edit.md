# EDIT · 精选

用户于 2026-11-06 确认的第三套主题，内部 ID `edit`，主题版本 `1.0.0`。用户说「第三套」「红色主题」「EDIT」「精选」或旧称「THE GOOD EDIT」时选择本主题；正式名称统一为 **EDIT · 精选**。`A Good Edit` 和「精选／留下真正重要的」是中英文示例内容，新稿按其主题另拟标题。

## 创建与文件

先查看 `assets/styles/edit/preview.png`、`preview-zh.png` 和 `artwork-preview.png`；完整成品为该目录的 `example-en.html` 与 `example-zh.html`。

```sh
python3 scripts/create_deck.py --style edit --prompt "做一份关于团队协作的演示" --out /absolute/path/to/new-deck
```

中文或混排输入默认中文，纯英文输入默认英文；用户明确要求英文时用 `--lang en`。`--prompt` 只帮助选择语言，创建的是二十四页示例副本；随后由 Agent 根据用户内容修改 `source/slides.html` 和 `deck.json`，再运行 `build_deck.py`。二十四页是样例规模，可以按内容增删、调序。

- 构建器直接读取 `source/style.css`，它包含完整主题布局、播放器配色与插图规则。修改工作副本时以此文件为准；不要只拼接 `theme.css` 和 `player-shared.css` 覆盖它，否则会丢失成品中的红色播放器规则。
- 中文构图调整在 `source/locale-zh.css`，仅作用于 `html:lang(zh)`；中文模板文案在 `locales/zh-CN/slides.html`，创建工作副本时会覆盖 `source/slides.html`。
- `source/artwork.css`、`artwork.js` 和 `artwork.html` 是独立的素材选择器，构建器自动内嵌。资源目录是 `graphics/`，完整名称、类别、关键词与文件路径见 `graphics/catalog.json`。
- `source/chart-recipes/` 保留四列卡片、六种柱形/构成图、六种分析图和目标进度的双语配方；可用 `scripts/render_edit_data_slides.py` 生成新的14页片段。它不覆盖源稿，不运行播放器，也不会只改标签而重新计算已交付HTML。用法与数据规则见 [edit-data-layouts.md](edit-data-layouts.md)。

## 视觉与排版

- 固定 1920×1080。暖纸白 `#f2eee7`、亮纸白 `#fcf8f0`、酒红墨色 `#352129`、校改红 `#b64032`；外部留边色 `#d8d1c9`。通过纸白、酒红整页和红色收尾形成节奏，不引入绿色金属主题的材质和强调色。
- 英文标题与正文使用 Instrument Serif（`EditSerif`），强调用真正的 Instrument Serif Italic（`EditItalic`），界面及短标签用 Instrument Sans（`ShiftSans`）。不要用合成斜体或替换成未经授权的商业字体。
- 中文使用完整 Noto Serif SC 可变字体（`EditCJK`，真实字重 200–900），以宋体的笔画反差呼应英文书刊风格。大标题默认 300，正文、标签、菜单和素材库用 400，深底及红底大标题用 400；不合成斜体、加粗或横向变形。界面中的英文仍用 `ShiftSans`。两种版本均内嵌完整中文字库与 OFL 声明，后续编辑新汉字也能离线显示，英文版既有字体与排版保持不变。覆盖与许可见 [typography.md](typography.md)。
- 让文字成为构图主体：错位标题、编辑划线、边注、细分隔线和纸页叠放。删改线应对应被删去的内容，不能为了装饰划掉关键结论；前后对照应保留原意。
- 原有十种视觉布局依次是：错位封面／从噪声中选出重点／选定核心／删改前后对照／内容顺序／留白／文字层级／校阅清单／三个衡量标准／红色结尾。它们是可复用的表达方式，不是固定讲稿。
- 中英文各30页保留原前9页，将四列卡片与13种信息图放在第10–23页，原红色收尾移到第30页。新增内容围绕稿件筛选、编辑与校阅；数字的示例性质保留在制作参考和 deck.json 的 data_provenance 中，不能当作外部事实引用；成品不添加示例或版式类型标签。图表不进入装饰素材替换槽，原24张SVG与四份字体配置保持不变。
- 第10–23页以编辑刊物的跨页构图组织证据：全宽柱条与折线、文档计数矩阵、共同比例的小图对照、表格与雷达、稿件纸条热力各自选用合适的空间，不统一套入卡片仪表盘。第10页是带罗马序号与折角的四张校样纸；第23页是酒红底上的一整张三行校阅清单，实际完成率、目标与百分点差分别可读。页面与数据对应规则见 [edit-data-layouts.md](edit-data-layouts.md)。
- 数据页标题区顶距为82px，左右各120px；图表区左120px、上340px、宽1680px、高610px，卡片与目标清单从350px开始。主标题及其说明的实际底边与下方内容至少相隔60px。换成更长的标题时按实测边界调整换行、字号与内容位置，不能仅凭固定坐标假定不会重叠。
- 中文按自身行长重排；不要将英文句子逐词替换后保留不合适的超大字号。保留正文、插图、页脚与底部导航间的距离；「留白」页不需要额外填图。
- 保留纸页轻入场、校改线展开、文字错峰和小幅插图倾斜，避免持续循环。关闭动效或系统减少动态时保持静态完整画面。
- 数据页内置有限时长的语义动画：柱条按轴展开、实线绘制、虚线用 `wipe-x` 揭示并保持原间隔、流带按路径层级展开、散点与热力单元错峰出现。象形校样等 `pop` 元素使用 `transform-box:view-box` 与 SVG 坐标中的自身中心，不能叠加 `fill-box` 造成位移。坐标轴不跟随数据整体平移；快速翻页、编辑、保存和PDF前统一完成并取消动画。实际时序与终态验收见 [edit-data-layouts.md](edit-data-layouts.md#图表进场与验收)。
- 鼠标使用可见主体约 23px 的朱红实心笔尖，以尖端作为点击位置；红底改用纸白主体，移动时留下两段快速消退的短墨迹，点击时短促轻压。不附加系统箭头、大勾或长墨线。行为与回退见 [player-contract.md](player-contract.md)。

## 24 张原创 SVG

这些素材是本主题的复用库，按内容选择即可，不必为每份演示重新生成图片。

| 类别 | 常见语义与素材示例 |
|---|---|
| 选择 | 重点、保留、观察：`kept-page`、`selection-window`、`index-tabs`、`focus-loupe` |
| 编排 | 顺序、结构、组合：`paper-sequence`、`paper-fan`、`accordion-fold`、`layout-ruler` |
| 删改 | 精简、修订、去除：`proof-pencil`、`cut-ribbon`、`editorial-scissors`、`correction-roller` |
| 校阅 | 检查、确认、交付：`folded-proof`、`editorial-clip`、`proof-stamp`、`bound-folio` |

完整 24 张以 catalog 为准，后扩充的 16 张带有 `added_version`，可在选择器的「新增」筛选中查看。它们以透明背景、1000×1000 viewBox、象牙白纸张、红漆文具、左上照明与柔和落影保持一致，全部为无脚本、无外链的纯矢量 SVG。原创素材使用随包 MIT 许可；字体与 PDF 库保留各自许可。

默认示例仅在第 **1、3、5、8、24** 页使用可替换插图。其余页保留文字或内容图解，不为了用完图库而逐页堆图。优先选择内置素材；没有贴切的图时可保持文字页，确需扩充时按同套材质和照明另做审核。

插槽置于既有 `.artwork-tilt` 容器内，使用唯一位置 ID：

```html
<div class="artwork-slot" data-artwork-slot="unique-slot-id"
     data-artwork-id="folded-proof" data-artwork-default="folded-proof"
     data-artwork-label="这一页的标题"></div>
```

构建时自动嵌入该图。图片保持插槽位置并按 contain 等比缩放；同一 SVG 可用在多个插槽，渐变 ID 由独立图像隔离。按新内容增加插槽时，先给它独立空间，不能覆盖正文。

## 替换、保存与验证

- 底部「替换素材」支持选目标页、按类别浏览、预览后应用、取消和恢复默认。没有配图的页面仍可打开库并选择现有配图页，不会自动覆盖文字页。模态框内滚动与键盘不触发底层翻页。
- 「下载 HTML」保留文字、当前图、完整 24 张素材库、字体和许可；保存后单文件离线打开仍能继续替换。未使用素材也要保留，才能兑现离线替换能力。
- 「下载 PDF」渲染已应用的文字与配图，不包含未应用的预览、导航或操作栏，也不打开打印窗口。导出时仅在副本中冻结 SVG `text` 与 `tspan` 的计算字体样式，保留实际字体、字重、字号和字距，避免离线栅格化丢失衬线大数字或百分号的样式；不改写演示源稿。它是高清静态画面 PDF，不具备 HTML 的编辑交互或可选择文字层。
- 按 [player-contract.md](player-contract.md) 检查共享播放器。新内容重点检查中文换行、前后对照语义、SVG 与文字的间距。若改替换或保存逻辑，再检查 24 张缩略图、取消／应用／恢复默认、保存后离线再替换，以及实际 PDF 中的当前插图。

文字较多的页面由 Agent 在生成时判断配图与布局，见 [content-layout.md](content-layout.md)。中英文二十四页样片展示视觉风格与布局能力，不限定新稿页数，也不要求逐页沿用样片配图。
