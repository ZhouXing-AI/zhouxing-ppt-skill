# BLEND · 融合

第十一套主题，内部 ID `blend`，版本 `1.0.0`。用户说「第十一套」「BLEND」「融合」「柔润组合主题」时选择本套。中英文示例标题为「让好想法相遇」／`Good ideas belong together`，内容为创意组合方法；新演示按用户题材另写内容，不把示例标题或三十页样稿结构当作限制。

## 创建与语言

查看 `assets/styles/blend/preview.png`、`preview-zh.png` 与 `artwork-preview.png`。完整样片为 `example-en.html`、`example-zh.html`，各三十页。

```sh
python3 scripts/create_deck.py --style blend --prompt "为一次跨团队创意工作坊制作演示" --out /absolute/path/to/new-deck
```

中文或混排输入默认中文版，纯英文默认英文版；用户明确指定输出语言时传 `--lang zh-CN` 或 `--lang en`。`--prompt` 只帮助选择语言，不自动重写样片。Agent 在工作副本中改文案、页数、版式与 `deck.json`，然后用 `build_deck.py` 编译。

- `source/style.css` 为页面与播放器样式，`source/locale-zh.css` 中的中文规则仅对中文语言生效。
- 中文内容、双语菜单和字体配置来自 `locales/zh-CN/`。英文只内嵌两套西文字体，中文版额外内嵌一套完整中文变量字库；切换语言不能仅修改 HTML 的语言属性。
- 字体、SVG、交互、PDF 依赖和各自许可随单文件内嵌，离线可用。

## 视觉系统

唯一网站参考为 [Butter Video](https://www.butter.video/)：灰白画布、黑色大标题、圆润小工具、艳色物件以及时间线组织关系。BLEND 转译为独立的创意组合演示，不使用该网站的钥匙串、挂件、Logo、应用图标、真实产品界面、原首屏构图、商业字体或文案。

- 主色为灰白 `#F4F3F0`、墨黑 `#17171A`、紫色 `#5D57F4`、蜜桃 `#FF986B`、淡紫 `#D7D0FC`、浅薄荷 `#C9E9DD`。这是本套适配色板；正文保持清楚对比，柔和半透明层次主要用于配图。
- 英文使用 Space Grotesk（`BlendSans`）真实 400/500/600，DM Mono Regular（`BlendMono`）真实 400 用于小型英文索引与数字。中文标题 Noto Sans SC 500、正文与界面 400（`BlendCJK`）。按中文短句独立断行，不压缩字形或伪造粗斜体，使用 `font-synthesis:none`。
- 三套均为完整官方字库及 SIL OFL 1.1，免费商业使用、嵌入和开源再分发依随包条款进行。Space Grotesk 原始变量范围 300–700，Noto Sans SC 为 100–900；三套 `fsType=0`。固定来源、完整版权、SHA、真实轴范围和 cmap 覆盖见本套 `fonts/`，不按样稿裁字。
- 大字与单件物品、居中观点、三项说明、四列工具、二维数据、三项反馈与横向实践流程交替组织页面。圆角用于工具和小模块，不把每页都排成相同卡格；正文与配图保持独立空间。
- 动效为文字短距离上移、逐组出现及插图淡入。没有持续漂浮、无限旋转或鼠标倾斜；关闭动效与减少动态时保留完整清晰画面。

| 布局 | 适合内容 |
|---|---|
| `cover` | 一句主张、独立物件与简短开场 |
| `manifesto` | 两行居中观点与少量颜色片段 |
| `ingredients` | 三项线索、条件或构成要素 |
| `toolkit` | 四项并列能力、工具或阶段 |
| `time` | 同一总量下的时间或资源分配比较 |
| `forms` | 一个核心想法与三种表达条件 |
| `testing` | 同一口径的多轮趋势及变化量 |
| `feedback` | 三项反馈、判断与调整建议 |
| `practice` | 四个有顺序的行动步骤 |
| `closing` | 下一步邀请与回到开始 |

文字较多时按 [content-layout.md](content-layout.md) 逐页重排，必要时减少装饰，保留信息图、表格与必要说明。成品没有「纯文字」开关。

## 两页二维数据示例

第 5 页 `time` 使用横向堆积条比较同为 40 小时的工作周：调整前“搭建/创作/复盘”为 12/16/12 小时，调整后为 6/24/10 小时。每小时使用相同长度，两条总宽相同；创作由 16 增到 24 小时，变化为 **+8h**。图例、每段时长与 40 小时总量说明直接显示，不能只改标签却保留旧几何。

第 7 页 `testing` 为六轮任务完成率：58%、63%、68%、76%、81%、86%。纵轴为 0–100%，横轴为第 1–6 轮，连接实际点位而不作平滑插值；首尾相差 **28 个百分点（pp）**，不是相对增长 28%。更换数据时同时更新路径、点、坐标范围、标签和旁侧结论。

两页保留必要指标与单位；虚构样例的来源记录在 deck.json，不在成品显示制作标签，也不代表实际调查或业务结果。数据图使用原生内联 SVG 和 `data-information-visual`，不进入装饰素材槽。图形的长度、轴与比例保持二维准确；不能套用配图的 3D 透视、挤出或光泽来扭曲度量。底部文字编辑不是图表数据编辑器，数据更改应由 Agent 在源文件中同步修改全部几何并重新验收。

## 三十页与新增内容布局

中英文样片各30页：原前9页保持，原收尾移到第30页，第10–29页补充20种内容布局。原24张素材和完整字体保持不变。新演示不受30页限制；按用户信息结构选择版式，不把示例值作为外部事实。

新增布局由 `source/expansion30.py` 的 `get_slides(lang='en')` 和 `validate_data()` 复现，支持 `en`、`zh`、`zh-CN`；样式在 `source/expansion30.css`，已追加到 `style.css` 和中文样式。每页带 `data-layout-id`。详见 [blend-data-layouts.md](blend-data-layouts.md)。

新增图表用主题原有字体和二维刻度，图表不属于装饰替换槽。没有四角品牌小字、示例数据或版式类型标签；必要单位直接保留。示例属性保留在 `deck.json` 与配方。标题整体上距80px、图区上距340px；字体与内容变更后重新验证间距和中文行长。

数据动效使用有限时长的 `data-chart-motion` 与 step；虚线采用 wipe-x，不用 draw。坐标系只淡入，数据按实际方向展开，不整图平移。所有动画进入同一播放器清理数组，快速翻页、关闭动效、编辑、保存HTML、PDF和减少动态时回到完整终态。PDF内联SVG文字计算样式后截图，保留本套实际字体。

## 24 张原创 SVG

`collect` 收集、`combine` 组合、`shape` 塑形、`release` 发布各六张。全部为初始完整库，不显示新增筛选。双语名称、关键词和用途见 `graphics/catalog.json`；原创图形采用随包 MIT 许可，字体与第三方代码保持各自许可。

透明 1000×1000 SVG，使用光滑软边、半透明色层、柔和高光和轻微厚度，表达线索、联结、变化与发布。图形本体为原创路径和渐变，不包含原站钥匙串、品牌形状、位图、外部字体或脚本。保持原色和 contain 比例，不跨主题套用改色或三维倾斜。

| 页码 | 插槽 | 默认素材 |
|---|---|---|
| 1 | `opening` | `soft-loop` 柔环 |
| 3 | `ingredients` | `split-prism` 分光棱片 |
| 4 | `toolkit` | `linked-petals` 联结花瓣 |
| 6 | `forms` | `ribbon-fold` 折叠缎带 |
| 8 | `feedback` | `feedback-dial` 反馈旋钮 |
| 30 | `closing` | `open-spark` 开放火花 |

插槽保留唯一 `data-artwork-slot`、当前 `data-artwork-id`、`data-artwork-default` 和对应语言的 `data-artwork-label`。默认六个配图位置可随新稿增删；不要求每页配图，也不因图表使用 SVG 就将其替换成装饰。

## 播放与导出

遵守 [player-contract.md](player-contract.md)。底部工具栏依次提供翻页/目录、编辑文字/替换素材、动效/下载 HTML/下载 PDF，全屏带图标并在最右。圆角短粒导航位于 16:9 画布内，当前项宽度变为三倍；浅底紫色、深底淡紫、紫底浅色，明确表示当前位置。

柔角三角拨片鼠标的可见主体约 22.67 CSS px，左上尖端对应真实热点，移动带两颗约 160ms 消退的圆角短粒。填充随背景明暗变化，静止后不持续动画；操作界面、编辑、触屏、关闭动效与减少动态恢复原生鼠标。

下载 HTML 保留文字、当前素材、完整图库、字体与许可；下载 PDF 使用当前已应用的内容，生成高清静态页，不弹打印窗口，也不包含导航、工具栏、鼠标或可编辑文字层。检查中英文实际字体、标题与物件边界、两页数据比例和标注、素材替换/取消/恢复、离线保存重开、滚轮、全屏及实际下载的 PDF。
