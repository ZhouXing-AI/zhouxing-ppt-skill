# 按内容组合图表

样片展示视觉语言和可用能力，不是固定的图表页码表。不能因为样片某页只有一组柱形，就把所有新稿限制为一组；也不能为了展示模板能力强行塞入多个图表。此约定适用于全部主题和中英文版本。

## 样片精选与实际生成是两件事

主题样片只需保留好看、有代表性的柱状图页面。同一图表家族的单柱、分组、堆叠、瀑布等变体不必各占一页，也不必全部缩小拼入一页；按用户要求合并展示时，可以精选一种代表表达，并移除重复的样例页。这里精简的是模板的示例覆盖，不是删改用户的真实数据。

实际生成用户演示时，不能受样片中选中的柱数、系列数、子图数量或所在页码限制。按内容重新计算和组织：需要一个就一个，需要两个或多个就多个，需要柱线混合就组合。样片只呈现一种形式，不表示其他形式不支持；需要多个真实数据页时也不强行压成一页。

## 横向柱状图也按实际需求生成

横向柱状图统一作为一个图表家族，样稿只保留一个有代表性的页面，不因单系列、前后对照或重点突出而重复占页。LENS 样稿保留第 06 页，但页码和样稿形式不约束新稿。生成时按类别数、系列数、排序语义、标签长度和比较目标调整：可以单系列、多系列并排、具备组成含义的堆叠，或在同一页组合其他图表；需要突出哪一条由用户内容决定，也可以全部保持默认态。前后对照要保留两组数据和比较口径，不能因为样稿是单系列就删除其中一组。条宽、行距、标签区和注释区按实际内容重算，英文独立检查；数据太多时分组或拆页，不把每种变体固定为单独模板，也不把真实内容强行合成一页。

## 折线图按趋势问题灵活生成

折线图样稿只保留一个代表页面，LENS 保留第 03 页；单线、多线、对照、目标线或带面积填充不需要重复占用样稿页。实际生成按时间跨度、采样间隔、系列数量与比较目的重新设计；可单图、多图、直接标注或与柱形组合，不受样稿页码、线数或深浅背景限制。必须保留用户的真实系列和数据，缺失值不连成已观测事实，不等时间间隔按真实间距绘制。示例去重不等于删除真实趋势内容。

## 先确定要回答的问题

识别每个指标的含义、类别或时间维度、单位、分母、系列、比较对象和必要条件，然后选择组合：

- 一个问题、一种度量：单图。一个系列可用单柱，多系列可用分组柱；同一类别内的组成才用堆叠，各组总和相同且关心比例时才用百分比堆叠。
- 同一结论需要两种或更多证据：一页可有两个或多个独立图表，按主次采用并排、上下、主图配小图或小倍图。每个子图保留独立标题和必要单位，避免把不兼容指标共用一条数轴。
- 同一类别或时间上的数量与趋势：可组合柱形与折线，或添加目标线、区间、关键事件。折线必须有连续或有序的语义，不能把无序类别连起来制造趋势。
- 相同度量跨群体比较：小倍图优先共享范围与刻度；确需独立范围时明确标注，不能让不同高度的满幅柱看似可比。
- 指标单位不同：默认拆成同页独立图表。确实需要双轴且用户目的明确时，每轴标明单位、系列归属和范围，解释共同时间维度；不能调轴以夸大相关性。
- 多个系列遮挡、图例过长或类别太多：先直接标注、分组、变横向、突出重点或用小倍图，再决定拆页。不得静默丢弃系列或类别；“其他”的聚合必须保留组成及口径。
- 数值排序适合横向条形；组成、流向、分布、相关、阶段与排期应选相应表达。可以同页组合不同类型，前提是服务同一个阅读问题，而不是拼凑图表目录。

## 图形必须忠实于数据

- 数量柱形以零为基线；负值从零向反方向伸出。若用截断轴，必须显式断轴标记并说明，优先选择其他表达。
- 堆叠不得混合不同分母或单位；百分比区分相对变化与百分点，四舍五入误差记录在制作资料中。
- 缺失值不等于零；折线在缺失处断开，或在确有依据时明确标出估计。时间间隔不等时按实际间隔定位。
- 同类系列颜色、线型、顺序跨页一致。区分实测、目标、预测及不确定区间；不要只依靠颜色。
- 材质只增强表面、高光和浅边缘。柱体的正面长度、面积与刻度保持准确，装饰侧面、阴影不能增加数据高度。
- 每页合并或重排后核对所有原数值、系列名、单位、分母与条件。共同主题可以合页，不能因都叫柱状图就混用口径。

## 留白和语言适配

先划分标题区、子图标题/图例区、绘图区、刻度/类别区和结论区。大数字与图表标签使用独立列或行，不让长标签伸入结论列。英文需要按实际字体重新测量，不能仅替换中文字串；必要时把类别名移到条形上方、合理换行、增大标签区。

图表数量不是固定值，子图数量与系列数量是两个不同决策。增加数量时重新计算列宽、行高、柱宽、组间距、图例和底部安全区；不要整体缩小已有截图。通常先尝试一至三幅有主次的图，更多时通过可读性检查再决定保留或拆页。空间不足时重组或拆页，而不是无限缩小字号。用户限定页数时优先去重和精简非必要说明，保留数据语义。

## 可复用 SVG 辅助函数

`scripts/chart_panels.py` 是无依赖、可选的原生 SVG 辅助函数。复制到新演示的源代码目录后调用；配色、渐变、字体、网格样式和动效接入由主题负责，不强制套用它的默认参数。

- `panel_boxes(count, width, height, gap)` 给出单列或双列的初始分区，不是自动排版/可读性保证。三幅以上应重新给足高度或改版；不能直接塞进同样的画布。
- `cartesian(labels, series, ...)` 支持同一非负坐标系的一条或多条柱形/折线系列。每条系列含 `type`、`values`、`fill`，可带 `name`、`color`、`suffix`。所有值必须匹配类别长度并处于显式范围内。
- 此辅助函数不支持负值、缺失值、堆叠、双轴、时间间隔或自动避让。遇到这些情况按上述规则扩展渲染器或另写合适图形，不修改用户数据来迁就函数。
- 多图分别调用渲染函数；同图柱线组合则传入多种 `type`。例如：

```python
from chart_panels import cartesian
body = cartesian(
    ['W1', 'W2', 'W3'],
    [
        {'type': 'bar', 'name': 'Delivered', 'values': [8, 12, 18], 'fill': '#47738B'},
        {'type': 'line', 'name': 'Target', 'values': [10, 14, 20], 'fill': '#8CAAB9', 'color': '#8CAAB9'},
    ],
    width=1500, height=590, maximum=30, step=10,
    title='Weekly delivery', unit='Improvements',
)
```

## 动效与验收

进场可以依次显现柱体或绘制曲线，但不得改变最终比例；支持关闭动效、减少动态、离开页面中止和重新进入重播。保存 HTML、离线重开和下载 PDF 都必须保留完整终态，不能残留遮罩或半截线。

用实际数据与实际语言截图检查：读图顺序、标签/图例碰撞、单位归属、零线、所有系列完整性和底部导航安全区。对混合图检查线与柱的类别坐标一致；对多图检查尺度是否应一致；对长英文检查真实字体尺寸。页码调整后同步导航、双语版本、缩略图与导出文件。
