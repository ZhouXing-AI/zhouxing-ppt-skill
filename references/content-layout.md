# 按每页内容决定布局与配图

SHIFT、FOCUS、EDIT 中英文样片各 24 页，其余九套各 10 页，展示已确认的视觉风格与布局能力。三套的图表复用分别见 [shift-data-layouts.md](shift-data-layouts.md)、[focus-data-layouts.md](focus-data-layouts.md) 与 [edit-data-layouts.md](edit-data-layouts.md)；BLEND 另有二维时间分配与折线示例，见 [blend.md](blend.md)。GROVE 的时间占比分配与每周贡献柱形示例见 [grove.md](grove.md)，准确比例、单位与必要图例必须保留，数据的样例属性记录在元数据和制作资料中。用户的新稿可以有较多文字，但不额外塞入固定的多文字展示页。排版判断由使用 Skill 的 Agent 在生成阶段完成，成品没有「纯文字」开关，浏览器也不负责理解内容后自动改版。

## 成品内容与制作信息

预览与实际生成使用同一份 HTML。删除制作标签应修改成品源内容，不使用只在截图、预览或 PDF 中生效的隐藏规则，也不交付仍含这些标签的生成模板。

- 画面不展示「示例数据」「ILLUSTRATIVE DATA」「四列卡片」以及标识版式或图表类型的制作标签。页面标题表达内容主题、判断或结论，不介绍模板能力。
- 单位、数轴、图例、数据对应关系、阅读所需条件和用户要求的来源属于内容，应留在图表或实义说明中，不与制作标签一起删除。
- 样例数据的属性、来源和假设留在演示元数据、数据配方与制作资料中。生成用户演示时，替换为用户提供或经核实的数据；资料不足时只按请求制作概念示意并记录假设，不能将模板数字或样例叙事当作真实外部事实。

## 先判断信息，再决定配图

逐页识别标题、结论、解释、数据、步骤与必须保留的限定条件。结合段落数量、句子长度、信息关系和实际字体占用空间判断阅读负担，不按同一字数阈值切换所有页面。

- 装饰 SVG 能强化该页重点，且正文有充足空间时保留；与内容无关或挤占阅读空间时省略。
- 数据图表、流程图、关系图和有语义的标记属于内容。保留它们及理解所需的数值、单位、图例、条件和用户要求的来源，不因其使用 SVG 格式而删除。
- 对上传的 PPT 逐页核对原内容。重排可改变位置和层级，但不得为了版面好看擅自遗漏结论、数字或约束；需要压缩原文时遵循用户对摘要和保真度的要求。

## 为较多文字重新构图

去掉装饰后，把释放的空间交给文字，并重新确定标题尺度、列宽、行长、对齐线和段落间距。不要保留空的配图容器，也不要只隐藏图片却维持拥挤的文字栏。

顺着内容关系组织阅读：连续论述可用单栏或宽窄主次栏；并列内容适合分栏；同一维度的比较才使用表格；步骤应有明确先后。沿用本主题字体、配色和视觉节奏，不把所有复杂页面做成相同表格或均分卡片。

正文以实际投屏可读为准，1920×1080 画布通常从 30–36px 试排，密集内容不低于 28px。保留底部导航安全区。仍放不下时按论点或步骤拆页，不无限缩字号，也不偷偷删掉必要信息；用户限定页数时先尝试重组和消除确实重复的表达，无法同时满足时明确说明取舍。

## 内部实现

复用现有主题构图时，可在需要以文字为主的 `section.slide` 上写 `data-content-layout="text"`。构建器只对该页添加 `.text-led`，使用本主题 `source/text-layouts.css` 中对应的文字排版规则；其他页继续自己的图文布局。纯装饰容器可标 `data-decoration`，信息图表不要放进该容器。

这个属性记录 Agent 已作出的排版决定，不是自动排版算法。已有文字变体主要适配原有十页构图；新增复杂页面仍需根据真实内容编写网格、弹性布局与换行规则，不能只加属性就视为完成。可编辑表格单元、独立列表文字使用 `data-edit="true"`，避免嵌套可编辑节点。

## 交付检查

按实际语言逐页截图，检查阅读顺序、完整性、文字溢出、图文关系与底部导航；有较多文字的页尤其要按正常展示尺寸看可读性。检查成品源内容、直接打开的 HTML、保存重开与实际下载的 PDF 都没有制作标签，且单位与实义说明完整。修改内部布局机制时，检查相邻图文页不受影响，保存 HTML 后离线重开与实际下载的 PDF 均保留该页构图。
