# GROVE · 共生

第十二套主题，内部 ID `grove`，版本 `1.0.0`。用户说「第十二套」「GROVE」「共生」「植物线描主题」时选择本套。中英文样片以「给成长，留点空间。」／`Make room for growth.` 开场，讲共同成长与社区协作；新演示按用户题材另写内容，不把示例主张、植物隐喻或三十页样稿结构当作限制。

## 创建与语言

查看 `assets/styles/grove/preview.png`、`preview-zh.png` 与 `artwork-preview.png`。完整样片为 `example-en.html`、`example-zh.html`，各三十页。

```sh
python3 scripts/create_deck.py --style grove --prompt "为社区共同成长工作坊制作演示" --out /absolute/path/to/new-deck
```

中文或混排输入默认中文版，纯英文默认英文版；用户明确指定输出语言时传 `--lang zh-CN` 或 `--lang en`。`--prompt` 只选择语言，不自动重写样片。Agent 在工作副本中改文案、页数、版式与 `deck.json`，再用 `build_deck.py` 编译。

- `source/style.css` 包含页面与播放器样式，`source/locale-zh.css` 中中文规则只对中文语言生效。
- 中文内容、双语菜单和完整字体配置来自 `locales/zh-CN/`。英文只内嵌两种西文字体，中文额外内嵌一种完整寒蝉半圆体；切换语言不能仅修改 HTML 语言属性。
- 字体、SVG、交互、PDF 依赖与许可随单文件内嵌，可离线使用。

## 参考范围与视觉系统

唯一网站参考为 [Therapy in London — Why Join](https://www.therapyin.london/why-join-therapy-in-london)。视觉依据是用户 Eagle 保存的正常首屏：暖浅底、深色轻柔大字、绿色植物线描、紫色室内物件和少量蓝色。官网文本用于确认网站为治疗师提供资料展示、客户连接和会员支持；GROVE 转译为一般社区协作内容，不提供医疗或治疗建议。

本次实时网页捕获的 CSS 未完整加载，部分画面是默认文字和放大的 SVG，不能当作原站深页设计证据。网页字体表声明 Figtree，但实际部分节点退回 Times，不把该回退当设计选择。原站动效未完整实测；本套动画和交互是独立设计，不声称复现其动态。

- 原创适配色板：暖奶油纸 `#F2EFDF`、深绿墨 `#253A31`、翠绿 `#4CA785`、浅叶绿 `#B8D7B8`、浅紫 `#B6A2D3`、少量蓝 `#6385D4`。它们是为幻灯片重新调和的颜色，不是从缩略图精确复原的官网 CSS 变量。
- 英文 Onest（`GroveSans`）使用真实 400/500，DM Mono Regular（`GroveMono`）400用于小型英文索引与数字。中文标题、正文与界面均用寒蝉半圆体 Regular（`GroveCJK`）真实400，按中文短句独立断行，通过字号、行距、位置和颜色区分层级，不伪加粗、伪斜体或压缩字宽。
- 三种字体均为完整官方原版文件、OFL1.1、`fsType=0`。Onest 原变量范围100–900；寒蝉半圆体 v1.805 为单一400字重，保留12,329个 Unicode cmap 码点、12,779字形，覆盖全部6,763个GB2312汉字。完整许可、保留字体名、固定来源、release/tag证据、SHA和覆盖文件随包保留，不按样稿裁字。CSS别名不改变内部字体名称，使用 `font-synthesis:none`。
- 原创彩色植物线描采用深绿轮廓、柔和色块和自然弯曲的线条，表达扎根、联结、照料和共同生长。保持平面、轻盈和清楚的负空间，不改成金属、树脂或厚重3D。
- 页面在图文分栏、居中观点、三项说明、四项条件、二维图表、分色流程、提问与收尾间变化。只在图像能强化信息时配图，不将所有内容做成相同卡格。
- 文字和配图短距离上移淡入、分组出现；不持续摇摆、漂浮或鼠标倾斜。减少动态与关闭动效时保留完整静态画面。
- 不使用原站的盆栽、台灯、蓝卡片、商标、文案或音视频，也不复刻其“左盆栽、右台灯、下方蓝卡、中央标题”的首屏位置关系。

| 布局 | 适合内容 |
|---|---|
| `cover` | 一句主张、独立植物物件和简短开场 |
| `principle` | 居中核心观点与三项关键词 |
| `roots` | 一组关系图像与三项基础条件 |
| `conditions` | 四项并列条件、能力或需要守护的事 |
| `allocation` | 一项重点比例与同口径时间或资源占比 |
| `direction` | 分色页面中的三个探索步骤 |
| `contributions` | 多个连续周期的贡献次数或同单位数量 |
| `listening` | 三个有层次的问题或反馈入口 |
| `commitment` | 深底页面中的三个明确行动 |
| `closing` | 简短邀请、共同生长的图像与回到开始 |

文字较多时按 [content-layout.md](content-layout.md) 逐页重排，减少装饰并将空间交给内容；保留信息图、表格与必要说明。成品没有「纯文字」开关。

## 两页二维数据示例

第5页 `allocation` 展示协作项目的时间占比：探索20%、创作40%、复盘25%、分享15%，四项合计100%。四条水平条形使用同一 **0–50%** 横轴，条长对应真实占比；40%的创作占比是页面强调项。完整标签、数字和“四项合计100%；横轴0–50%”说明直接显示。不要把每条背景轨道误当100%，也不要只改数字却保留旧长度。

第7页 `contributions` 展示第1–6周每周贡献次数：12、18、25、31、40、48。纵轴为 **0–50次**、从零起算，柱高按同一比例绘制；横轴标第1至第6周，柱顶保留数字。旁侧的 `12 → 48` 表达第一周与第六周的变化，不是六周总和；每周值不是累计值。更换数据时一并更新柱高、刻度、数值标签和旁侧结论。

两页保留必要指标与单位；虚构样例的来源记录在 deck.json，不在成品显示制作标签，也不代表实际社区统计或研究结果。图表为原生内联 SVG，带 `data-information-visual`，不进入装饰素材替换槽。度量保持二维，不能以植物大小、透视、挤出或装饰性曲线扭曲数据。底部文字编辑不是图表数据编辑器；Agent 修改数据后须同步更新全部几何与标注并重新验收。

## 三十页与新增内容布局

中英文样片各30页：原前9页保持，原收尾移到第30页，第10–29页补充20种内容布局。原24张素材和完整字体保持不变。新演示不受30页限制；按用户信息结构选择版式，不把示例值作为外部事实。

新增布局由 `source/expansion30.py` 的 `get_slides(lang='en')` 和 `validate_data()` 复现，支持 `en`、`zh`、`zh-CN`；样式在 `source/expansion30.css`，已追加到 `style.css` 和中文样式。每页带 `data-layout-id`。详见 [grove-data-layouts.md](grove-data-layouts.md)。

新增图表用主题原有字体和二维刻度，图表不属于装饰替换槽。没有四角品牌小字、示例数据或版式类型标签；必要单位直接保留。示例属性保留在 `deck.json` 与配方。标题整体上距80px、图区上距340px；字体与内容变更后重新验证间距和中文行长。

数据动效使用有限时长的 `data-chart-motion` 与 step；虚线采用 wipe-x，不用 draw。坐标系只淡入，数据按实际方向展开，不整图平移。所有动画进入同一播放器清理数组，快速翻页、关闭动效、编辑、保存HTML、PDF和减少动态时回到完整终态。PDF内联SVG文字计算样式后截图，保留本套实际字体。

## 24 张原创 SVG

`seed` 播种、`connect` 联结、`nurture` 培育、`flourish` 共生四类各六张，初始完整库不显示新增筛选。双语名称、关键词与用途见 `graphics/catalog.json`。原创 SVG 采用随包 MIT 许可，字体和第三方代码保持各自许可。

透明1000×1000画布，使用原创路径、深绿轮廓、柔和填色与少量细节线表达种子、根系、叶片和共同空间。不含原站图像、商标、位图、外部字体或脚本。保持本套原色和 contain 比例，不跨主题套用改色、浮雕效果或三维倾斜。深绿细线优先放在奶油、浅叶绿或浅紫底；深底使用时添加浅纸色承托，确保细节清楚。

| 页码 | 插槽 | 默认素材 |
|---|---|---|
| 1 | `opening` | `seed-cradle` 种子摇篮 |
| 3 | `roots` | `root-bridge` 根系桥 |
| 4 | `conditions` | `leaf-window` 叶之窗 |
| 6 | `direction` | `branch-compass` 枝间罗盘 |
| 8 | `listening` | `listening-bloom` 倾听花 |
| 30 | `closing` | `shared-canopy` 共生树冠 |

插槽保留唯一 `data-artwork-slot`、当前 `data-artwork-id`、`data-artwork-default` 和对应语言的 `data-artwork-label`。新稿可增删默认配图位置；不要求每页有配图，也不因图表采用 SVG 就将它归入装饰库。
