# SKETCH · 构想

用户于 2026-11-07 要求收录的第七套主题，内部 ID `sketch`，版本 `1.0.0`。用户说「第七套」「SKETCH」「构想」「手稿主题」时选择此套。英文样稿 `Good ideas start unfinished` 与中文样稿「好想法，从草稿开始」是原创概念内容，主题名称不限制用户演示的标题或题材。

## 创建

查看 `assets/styles/sketch/preview.png`、`preview-zh.png` 与 `artwork-preview.png`；中英文完整三十页样稿为 `example-en.html`、`example-zh.html`。

```sh
python3 scripts/create_deck.py --style sketch --prompt "为创意团队做一份工作方法演示" --out /absolute/path/to/new-deck
```

中文或混排输入默认中文，纯英文默认英文；用户指定语言时显式传 `--lang zh-CN` 或 `--lang en`。模板复制后，按用户内容重写文案、页数和构图，再运行 `build_deck.py`。不把样稿当作不可变的三十页填空表。

- `source/style.css` 保存完整英文排版与播放器视觉，`source/locale-zh.css` 仅作用于 `html:lang(zh)`。
- `locales/zh-CN/` 保存中文文案、菜单和字体配置；中文版本额外内嵌完整中文字库，不能只切换 `lang`。
- 素材、字体、脚本、PDF 依赖与许可全部内嵌到单文件 HTML，支持离线浏览与继续编辑。

## 视觉语言

唯一参考为 [Drool Design Studio](https://www.drool.design/)：纸白、薄荷绿、墨黑，粗衬线大字、细线描绘和轻微错位的纸张层。借鉴这套视觉关系，插图与页面构图重新设计；不使用其商标、室内场景、熔岩灯、原站图像或商业字体 Recoleta。

- 纸白 `#F4F1EC` 为主画面，薄荷绿 `#AAF0CE` 作整页、选中与强调，墨黑 `#212121` 用于文字和少量转折页。次级纸灰 `#E6E2DA`，无彩色渐变。
- 标题与插图有各自明确的空间。纸片可轻微旋转，但文字不应压到插图或装饰线；内容多时减少装饰，为该页重新安排文字区。
- 英文使用 Fraunces 600/700（`SketchSerif`，SOFT 100、opsz 72）与 Poppins 400/500（`SketchSans`）。中文标题用狮尾四季春加糖 SC Black 900（`SketchCJKDisplay`），正文、标签和界面用霞鹜文楷 GB Regular 400（`SketchCJK`）。真实字重、正常汉字字距，禁止伪加粗或横向压缩。
- 中文标题独立断句与安排字号，不套用英文的负字距；以厚实标题和较轻的手写正文形成层级。英文品牌标记及数字保留原字体。
- 动效为文字短距离淡入、纸张轻微转正、细线展开；无持续漂浮或跟随鼠标的三维倾斜。减少动态时保留全部内容。
- 本套鼠标为约 23 CSS px 的实心铅笔笔尖，墨黑/薄荷填充随背景切换，尖端对应点击热点，移动时有两段短墨迹。操作界面、编辑、触屏、减少动态恢复原生鼠标。

| 布局 | 适合表达 |

| `cover` | 三行主张、简短引言与纸张插图 |

需要长文字、数据、表格时按 [content-layout.md](content-layout.md) 判断，每页可采用新的文字主导构图；不是隐藏图片后保留空洞。样片保持简洁，不提供观众端「纯文字」开关。

## 24 张原创 SVG

四类各六张：`discover` 发现、`compose` 组合、`test` 试验、`act` 行动。原八张保留，新增十六张带 `added_version: "1.0.0"`；名称、用途与双语关键词见 `graphics/catalog.json`。完整素材库供后续选用，不要求三十页使用全部图。

800×800 透明 SVG，墨黑细线、少量斜线排线、纸白和薄荷平面填色；无位图、外链或字体依赖。不混入其他主题的金属雕塑或浮雕，不靠替换颜色重复凑数。原创图形随 MIT 许可分发，字体与第三方库使用各自许可。

默认配图在第 1、3、5、7、8、30 页；第 6 页的发散/收敛关系图属于信息内容。默认配图插槽可随新内容增删，使用唯一 `data-artwork-slot`、当前 `data-artwork-id`、`data-artwork-default` 与对应语言的 `data-artwork-label`。黑底页面用纸白图纸承托本色插图，不采用 FORM 的蓝色映射或鼠标倾斜。

## 播放与交付

遵守 [player-contract.md](player-contract.md)。画布内底部是纸片方点导航，当前方点填薄荷绿并加宽。底部操作栏包含编辑、替换素材、动效、下载 HTML、下载 PDF，带图标的全屏位于最右。全屏保持可见鼠标，操作栏到达底部显示、离开快速隐藏。

检查中英文各三十页、中文实际字体、无越界和遮挡；24 张图与四类各六张完整，新增筛选正常。验证替换、取消、恢复默认、编辑后下载再离线打开，实际下载 PDF 保留字体与当前插图。PDF 为高清静态栅格页面，不含可编辑文字层。

## 三十页样稿与数据扩展

中英文各30页，原前9页的内容和动效保留，原结尾移到第30页；第10–29页增加20种内容布局，见 [sketch-data-layouts.md](sketch-data-layouts.md)。本主题版本保持1.0.0，24张原创素材和完整字库不变。新增页面讲述观察、收集、试验和分享；纸白与薄荷、墨黑细线、校样纸片、粗衬线数字。新增页面使用纸张轮廓与二维图形，不引入金属材质。

新增页不是每页一套相同卡片：全宽图、左右分栏、关键大数、并列小图、完整表格、时间轴与逻辑流程交替使用。标题与说明整体从80px开始，图文区从350px开始，按实际字体测量至少60px间距。中文采用本套既有字体独立安排标题及标签，不机械沿用英文负字距。

工作副本的 `source/expansion30.py` 暴露 `get_slides(lang='en')` 和 `validate_data()`，可重生成这20页。所有数值是本地原创概念数据，来源属性留在两份 `deck.json` 的 `data_provenance` 与配方中，成品不展示示例/制作标签。用户提供真实资料后，同时重算数据、单位、SVG几何与结论，不能仅编辑数字标签。样稿不是固定30页的填空表。

图表只使用有限时长的显现动画；`source/chart-motion.js` 返回的全部效果加入既有播放器 `animations`，由同一个 `finish()` 生命周期清理。原页动效不变，信息图不随正文整体平移。保存、编辑、目录、关闭动效和PDF导出时保留完整终态。PDF导出副本冻结SVG `text`/`tspan`的实际字体样式，保留衬线数字和百分号字级；原稿不被导出过程改写。
