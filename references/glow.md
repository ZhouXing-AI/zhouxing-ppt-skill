# GLOW · 晴光

用户于 2026-11-07 要求完整制作并收录的第八套主题，内部 ID `glow`，版本 `1.0.0`。用户说「第八套」「GLOW」「晴光」「复古阳光主题」时选择本套。英文样稿 `Good things happen together` 与中文样稿「好事，一起发生」围绕共同体验与相聚；新演示的标题、题材和页数按用户内容决定。

## 创建

先查看 `assets/styles/glow/preview.png`、`preview-zh.png` 与 `artwork-preview.png`，完整中英文样稿为 `example-en.html` 和 `example-zh.html`。

```sh
python3 scripts/create_deck.py --style glow --prompt "为社区活动做一份策划演示" --out /absolute/path/to/new-deck
```

中文或混排输入默认中文，纯英文默认英文；明确语言时传 `--lang zh-CN` 或 `--lang en`。在工作副本重写文案、页数、排版与元数据，然后用 `build_deck.py` 构建。样片不限制新内容必须是活动策划。

- `source/style.css` 是完整视觉与播放器样式；中文适配位于 `source/locale-zh.css`，仅作用于 `html:lang(zh)`。
- 中文文案、菜单和字体配置来自 `locales/zh-CN/`。英文 HTML 仅内嵌西文字体，中文额外内嵌两种完整中文字库，不能只切换 `lang`。
- 字体、24 张 SVG、播放器和 PDF 依赖与许可全部内嵌到 HTML，支持离线使用。

## 视觉与字体

唯一参考为 [Sunfreaks](https://www.forsunfreaks.com/)：糖果粉、柠檬黄、暖奶油色，复古高对比衬线字、海报尺度、标签与邮票元素。参考站是防晒品牌，本套改为相聚主题；不使用其商标、防晒产品、摄影、视频、广告文案或商业字体。避免复刻原站首屏的品牌构图。

- 奶油 `#FFF1D2`、粉 `#F58ACB`、黄 `#FFE63B` 为主要色面，可可棕 `#422532` 用于文字和深色转折页，橘色 `#D9653B` 仅作小面积补色。
- 标题大、留白明确，照片位置由原创徽章式图形重新组织。圆形活动窗口、整页观点、三项节奏、双向关系和左图右文交替使用，避免每页都堆相同卡片。
- 英文标题为 DM Serif Display Regular 400（`GlowDisplay`），强调使用同款真 Italic 400（`GlowItalic`，字体元数据与 CSS 都指定 `style: italic`）；正文 Poppins 400/500（`GlowSans`）。不合成粗体或斜体。
- 中文标题使用 Noto Serif SC 900（`GlowCJKDisplay`），正文、界面使用 Noto Sans SC 400（`GlowCJK`）。与 FOCUS/EDIT 的轻宋字重不同，本套用重宋表达复古海报的厚实层级。中文强调用颜色、字号与字重，不倾斜汉字；所有中文保持正常字形比例与接近正常的字距。
- 各字体完整 cmap、固定来源、SHA256、OFL 许可与来源声明见 `fonts/font-manifest.json` 和 `fonts/NOTICE.txt`，未按样稿文本子集化。英文字体元数据含 `style`，构建器缺省仍为 normal。
- 入场为文字短距离上移和贴片轻微转正；不持续漂浮、旋转或随鼠标倾斜。

## 24 张原创 SVG

四类各六张：`arrive` 到场、`connect` 相聚、`play` 玩乐、`keep` 留存。名称、双语关键词、用途与文件见 `graphics/catalog.json`。此套的 24 张为初始完整库，不标记为从旧库新增。

透明 800×800 SVG，粗可可棕轮廓、平面粉黄奶油填色、少量橘色错位厚边和克制高光，表达复古印刷徽章与柔润贴片。太阳采用抽象闪芒核心；各图具有不同轮廓和语义，不用重复换色凑数量。无字体、位图、外链与脚本，原创图形采用随包 MIT 许可。

默认第 1、3、5、6、7、9、30 页配图，第 6 页三个活动插槽，共九个可替换位置；第 4 页节奏线和第 8 页双向箭头属于信息关系。并非每页都配图，也不要求 24 张全部出现在样片中。宽扁图根据内容选择插槽比例，不做蓝色浮雕或金属材质变换。

每个位置需唯一 `data-artwork-slot`、当前 `data-artwork-id`、`data-artwork-default` 和对应语言的 `data-artwork-label`。替换后保持 contain 缩放，取消不应用；保存 HTML 保留完整素材库和当前插图，PDF 使用当前已应用图形。

## 播放与交付

遵守 [player-contract.md](player-contract.md)。画布内底部采用小太阳页点，当前为加宽柠檬椭圆；不把导航放到 16:9 外。奶油圆角工具栏包含编辑、替换素材、动效、下载 HTML、下载 PDF，全屏带图标并在最右。

鼠标为约 23 CSS px 实心四角闪芒，中心对应真实热点，随深浅背景调整填充，移动带两个短光点并在约 160ms 后消退。编辑、操作区、触屏、减少动态与关闭动效恢复原生鼠标。

逐页检查中英文实际排版与字体、24 张素材及四类数量、素材替换/取消/恢复、编辑保存离线重开、滚轮与全屏。实际下载的 PDF 为高清栅格静态页，不带可编辑文字层；工具栏、导航与鼠标不进入 PDF。

## 三十页样稿与数据扩展

中英文各30页，原前9页的内容和动效保留，原结尾移到第30页；第10–29页增加20种内容布局，见 [glow-data-layouts.md](glow-data-layouts.md)。本主题版本保持1.0.0，24张原创素材和完整字库不变。新增页面讲述到场、相聚、玩乐和留存；奶油、粉、柠檬黄和可可棕，圆润数据条、印刷轮廓与复古衬线大数字。统计比例不由装饰厚度编码。

新增页不是每页一套相同卡片：全宽图、左右分栏、关键大数、并列小图、完整表格、时间轴与逻辑流程交替使用。标题与说明整体从80px开始，图文区从350px开始，按实际字体测量至少60px间距。中文采用本套既有字体独立安排标题及标签，不机械沿用英文负字距。

工作副本的 `source/expansion30.py` 暴露 `get_slides(lang='en')` 和 `validate_data()`，可重生成这20页。所有数值是本地原创概念数据，来源属性留在两份 `deck.json` 的 `data_provenance` 与配方中，成品不展示示例/制作标签。用户提供真实资料后，同时重算数据、单位、SVG几何与结论，不能仅编辑数字标签。样稿不是固定30页的填空表。

图表只使用有限时长的显现动画；`source/chart-motion.js` 返回的全部效果加入既有播放器 `animations`，由同一个 `finish()` 生命周期清理。原页动效不变，信息图不随正文整体平移。保存、编辑、目录、关闭动效和PDF导出时保留完整终态。PDF导出副本冻结SVG `text`/`tspan`的实际字体样式，保留衬线数字和百分号字级；原稿不被导出过程改写。
