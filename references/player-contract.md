# 播放器约定与验收

这些来自用户对最终成品的明确选择，适用于本 Skill 的演示播放器。

- 预览、实际生成、保存后重开和 PDF 使用同一份成品 HTML，不制作只在预览生效的隐藏层。页面源内容不放「示例数据」「ILLUSTRATIVE DATA」「四列卡片」或图表类型等制作标签；直接打开与下载后的演示必须一致。必要单位、图例和实义说明保留；样例数据属性及假设写入元数据与制作资料，不作为真实外部事实传播。

- 固定1920×1080画布，完整等比缩放。屏幕比例不同允许留边，不裁切正文。
- 测量视口用 documentElement.clientWidth/clientHeight。真实触屏设备的 innerWidth 可能被初始超宽画布撑大，导致缩放反馈。
- 导航是 #stage 的子元素，绝对定位于16:9画面内部底部。没有独立胶囊底座。前序实心、后序空心、当前长标；深浅配色保持对比。悬停显示页码与标题，点击跳页。导航状态跟随页面顺序和总数自动生成。
- 导航沿用各主题的深浅配色：SHIFT 暖色页使用棕黑当前标记，浅灰或深棕页可用铜橙，hero 等渐变页需显式 data-nav-tone="warm"；EDIT 浅纸页使用校改红，酒红或红色页使用浅纸色；INDEX 使用微型档案页签，深底页浅白、黄底等浅色页深黑，当前页签加宽。AXIS 使用工程短刻度与当前加宽实心块，深底暖白、浅底石墨色。通过页面 tone 设置对比，不根据固定页码猜配色。
- 底部操作栏在窗口模式常驻，画布为其预留 78px；全屏画布正常最大化，操作栏自动收起，鼠标到屏幕底部 88px 区域显示，离开约 120ms 后开始隐藏，100ms 淡出；移动过程中不反复延后隐藏计时。悬停操作栏或键盘焦点可见时不隐藏。T 也可唤出；触屏全屏保留操作栏。全屏操作栏显示时暂隐导航点，避免重叠。
- 手机操作栏可横向滚动以访问全部功能，不把按钮挤得过小。
- 十二套使用已确认的实心鼠标：SHIFT 铜橙游标、FOCUS 实心镜片、EDIT 朱红笔尖、FORM 实心刻片、INDEX 档案页签、AXIS 精密箭头、SKETCH 铅笔笔尖、GLOW 四角闪芒、ECHO 水滴拨片、SPARK 闪电楔、BLEND 柔角拨片、GROVE 叶尖。可见主体约 23 CSS px（原方案的 2/3），按实体轮廓衡量，不把 SVG 外框尺寸当作主体尺寸。它们在内容画布内替代原生箭头，不随幻灯片缩放放大，全屏仍保持可见。SHIFT 游标尖端、FOCUS 镜片中心、EDIT 笔尖、FORM 刻片中心、INDEX 页签左上角、AXIS 箭头尖端、SKETCH 铅笔尖端、GLOW 闪芒中心、ECHO 拨片尖端、SPARK 闪电楔左上尖端、BLEND 拨片左上尖端、GROVE 叶尖左上端分别对应真实点击热点。
- 实心填充随浅底、主题色底及深底调整，避免主体与背景同色；不能只靠细描边挽救可见性。移动时按主题显示 2–3 段短拖尾：粒点、镜片余影、短墨迹、切面余影或页签残影。拖尾在主体之外延伸约 12px，跟随实际移动方向，停下后约 160ms 消退；不叠加大型光环、长划线或无限粒子动画。
- 自定义鼠标与拖尾不拦截点击。操作栏、导航按钮、目录、素材选择器和文字编辑使用原生鼠标；关闭动效、减少动态、触屏或脚本未启用时也保留原生鼠标。离开画布、窗口失焦或页面隐藏时及时清理。静止后停止动画循环，点击反馈短促且不扩张成大型装饰。
- 鼠标滚轮向下下一页、向上上一页。按整次手势限一页，含触控板惯性锁与 300ms 冷却，累计 2px 即触发，120ms 无滚动视为手势结束；忽略水平滚动、缩放组合键、编辑状态、目录和操作栏内滚动。
- ←/→、空格、滑动翻页；F全屏，O目录，E文字编辑。点过按钮后方向键仍需有效；只有空格在按钮上时保留按钮激活语义。
- 下载 HTML 保留字体/许可/编辑结果与主题鼠标定义，清理临时提示、菜单状态、鼠标与拖尾运行节点和动态生成目录/导航，重新打开不得出现重复或停留在旧位置的鼠标。
- 下载 PDF 一页一张：内嵌 html-to-image 和 pdf-lib（MIT），本地渲染每页 2880×1620 画面，再生成 960×540pt 的 PDF 页面。保留字体、SVG 点群透明度和最终静态布局，隐藏导航、工具、鼠标、重看按钮与编辑提示。无打印对话框、无服务器；PDF 为高清栅格静态页，不含可选择的文字层。导出显示页数进度，防重复点击，结束后恢复操作。

## 输出前

优先使用本环境可用的浏览器工具或已安装渲染运行时，不要求用户安装一套固定测试环境。

1. 所有页截图逐页看文字越界、图形遮挡和视觉平衡，不能只看scrollHeight。
2. 普通窗口为操作栏留空间；16:9、16:10 全屏导航在画布内，正文不相撞，缩放比例保持16:9。
3. 窗口操作栏常驻；全屏底部唤出、离开延迟隐藏，焦点/悬停时可持续操作。滚轮长事件串只翻一页，编辑和目录滚动不翻页。
4. 点导航、目录、方向键和滑动后只有一个当前点；窗口和全屏内容区的实心鼠标均可见且大小一致，原生鼠标与自定义鼠标不重影。验证主体实际尺寸、热点位置和不同背景填充，并观察真实移动的短拖尾及停止后的消退。操作栏、编辑、目录和素材选择器恢复原生鼠标；关闭动效、减少动态、触屏、失焦、保存重开均无残留指针或拖尾。
5. 如果改播放器或编辑功能，验证编辑保存再离线重开；实际点击下载 PDF，在断网状态核对页数和逐页画面；导出不应调用 window.print。只改文案时不必重复所有交互测试。

- 全屏按钮带展开/收起图标，位于底部操作栏最右侧；状态切换及保存再打开后保留图标与正确语言。

- 不提供“重播动效”按钮或 R 快捷键；保留动效开关和正常翻页入场动画。

## 十二套图表动效

PDF 导出副本必须保留 section 原有内联样式及 CSS 自定义变量，再覆盖导出用的尺寸和位置。禁止直接用新的 `style.cssText` 覆盖原样式，否则使用页面变量的浅色或彩色背景会在 JPEG 中变黑。导出时同时冻结 SVG 文字的计算样式；最终检验必须看实际 PDF 的背景、字形与图表，不能只检查页数或文件成功下载。

`source/chart-motion.js` 是可选主题运行时，构建器在 `player.js` 前内嵌。`.reveal` 用于标题与说明；`data-chart-container` 只淡入，排除整图位移。数据元素的 `data-chart-motion` 支持 `draw`、`wipe-x`、`grow-y`、`grow-x`、`pop`、`fade`，`data-chart-step` 使用非负整数表示错峰分组。网格、坐标轴和刻度不标记为绘线对象。`draw` 仅用于实线；虚线使用遮罩或显现效果，保留虚线语义。展开通过临时遮罩完成，不改最终坐标、长度、厚度或原始数值。

运行时返回的所有 WAAPI 效果必须纳入播放器的统一生命周期：翻页、关闭动效、进入编辑或目录、保存HTML与下载PDF前，完成并取消效果；正常播放结束也取消图表效果，恢复原始SVG。减少动态时默认不播放并清理在途效果。初始HTML保持完整静态终态，不能留下隐藏用的内联样式、改写的虚线间隔或运行时遮罩。

修改图表动画后必须实际播放并按时间抽帧，至少覆盖进入时、中段和结束后；终态与关闭动效的同页对照。检查折线虚线、桑基两层流带与十个流量、散点标签和全部热力单元，轴不漂移、终态不缺项。再检查快速来回翻页、中途关闭动效、减少动态、进入编辑/目录，以及动画中保存后离线重开、实际下载PDF；上述结果须完整且比例不变。静态最终截图与DOM边界检查无法单独证明动画正确。

## 十二套素材替换

十二套主题的操作栏均含「替换素材」，全屏按钮仍在最右。每套分别使用自己的 24 张 SVG 库，可选择目标插槽、分类浏览、预览后应用和恢复默认，取消不改变当前图片。模态框内的键盘、滚轮、触摸不触发底层翻页。图片按既有插槽 contain 缩放，不覆盖正文。只在编辑模式点击配图时打开；FOCUS、EDIT 保留配图微动效，FORM 的浅浮雕只淡入，INDEX 的平面插图短距离平移淡入，这些主题不随鼠标倾斜。AXIS 插图短距离轴向移入，文字错峰出现，细线展开，不持续旋转或漂浮。

下载 HTML 同时保留当前图片 ID、图片本体与完整素材库，移除选择器临时 DOM 和倾斜状态；重新打开可继续替换。PDF 从当前已应用的插图渲染，不包含预览中的未应用选择。正文不含插槽的页面允许选其他已有配图页面，不自动插图。

FORM 的浮雕在灰白页使用原色，在 `data-tone="dark"` 的钴蓝页由 `artwork.js` 中 `sourceFor()` 按 SVG 六位 HEX 色值生成同色变体。预览、应用、保存重开与 PDF 均应保持当前页面的配色；同一素材不用拆成两个库条目。插槽使用 `.artwork-relief`，不添加 `data-tilt`。它的画面内导航沿用钴蓝／浅白的短刻度与当前长标，随页面 tone 切换对比。

INDEX 保留原六张平面插图并新增十八张，`collect`、`sort`、`connect`、`use` 各六张，新增项标记 `added_version: "1.0.0"`。默认插槽在第 1、4、7、30 页，使用唯一 `data-artwork-slot`、当前 `data-artwork-id`、`data-artwork-default` 和 `data-artwork-label`；可随内容增删，不要求每页配图。插图保留原色和纯平面轮廓，不增加渐变、阴影、三维倾斜或 FORM 的颜色转换。英文菜单来自只含英文的 `source/ui.json`，中文版采用 locale 的双语菜单和完整中文字体；保存重开后保留对应语言与完整图库。验证素材替换时一并检查分类各六张、新增十八张、应用／取消、保存重开、移动端和实际 PDF。

FOCUS 中英文样稿现为各30页，原收尾移到第30页。五个默认可替换雕塑位置为第1、3、4、8、30页，24张素材库保持不变；新增13种数据图表均是信息内容，不进入装饰替换槽。导航、目录和下载PDF按实际30页生成，复核数据SVG文字与渐变后再交付。

EDIT 中英文样稿各30页，第10页为四列校阅卡片，第11–23页为13种数据图表，原收尾移到第30页。默认装饰素材位于第1、3、5、8、30页，24张纸张与红漆文具SVG不变；信息图表不进入替换槽。柱体从基线展开、折线沿路径绘出、桑基分两阶段展开、散点与热力分组出现；所有效果有限时长，静态SVG保留完整终态。编辑、保存与PDF下载前由统一播放器结束动画。

SHIFT 的 24 张点阵 SVG 由原七张及十七张新增素材组成。四个默认可替换装饰插槽在第 1、6、8、30 页；SIGNAL、GRID、CLUSTER 是保留的信息图。默认插槽可用内联 SVG 保留点群动效，替换后使用离线 SVG 图片，深色页自动把深墨色映射为纸白以维持对比度。

AXIS 的 24 张原创结构 SVG 按 `structure`、`direction`、`feedback`、`capacity` 四类各六张，原八张保留、新十六张可用新增筛选。中英文共享原色图库，英文仅内嵌西文字体，中文额外内嵌完整 Noto Sans SC。默认配图位于第 1、3、6、9、30 页，按内容增删；保持原图比例，不添加鼠标倾斜。

SKETCH 的 24 张纸张手绘 SVG 按 `discover`、`compose`、`test`、`act` 四类各六张，保留八张、新增十六张。默认第 1、3、5、7、8、30 页配图，保留纸白与薄荷本色，黑底用图纸承托；入场轻微转正与淡入，不做持续漂浮或鼠标倾斜。方形纸片导航在画布内，当前填薄荷并加宽。素材库及完整中文字库随 HTML 保存，英文菜单仅显示英文关键词。

GLOW 的 24 张粗轮廓复古徽章 SVG 按 `arrive`、`connect`、`play`、`keep` 四类各六张，初始完整库不显示新增筛选。九个默认插槽位于第 1、3、5、6（三个）、7、9、30 页；图形保持粉黄奶油和可可棕本色，入场小角度转正，不持续漂浮。太阳导航点位于画布内，当前为加宽柠檬椭圆。四角闪芒鼠标采用中心热点，两个短光点随实际移动消退。

ECHO 的 24 张声学玻璃 SVG 按 `listen`、`tune`、`connect`、`resonate` 各六张，初始完整库不显示新增筛选。第 1、3、4、6、8、30 页默认配图，保持原色与 contain 比例；短距离淡入，不持续运动。音阶短柱导航位于画布内，当前项加宽；分栏页使用明暗双层轮廓。实心水滴拨片以尖端为热点，两个短弧尾随移动消退；分栏页按实际左右区即时适配鼠标填充，不按固定页码判断。

SPARK 的 24 张荧光树脂模块 SVG 按 `start`、`shape`、`test`、`advance` 各六张，初始完整库不显示新增筛选。第 1、3、4、6、7、30 页默认配图，保留荧光绿、深绿侧面及墨黑结构，按 contain 显示；轻微上移淡入，不添加鼠标倾斜或持续漂浮。斜切导航位于画布内，当前项加宽并描边；黑色操作栏沿用统一功能顺序。闪电楔主体约 22.67 CSS px，左上尖端为热点；移动带两段短切片尾，约 160ms 消退，深底荧光绿、浅底与绿底墨黑。

BLEND 的 24 张柔润半透明组合 SVG 按 `collect`、`combine`、`shape`、`release` 各六张，初始完整库不显示新增筛选。第 1、3、4、6、8、30 页默认配图，按 contain 保留原色与柔和层次，短距离上移淡入，不持续漂浮或随鼠标倾斜。第 5、7 页的二维时间分配与折线为信息图，不进入装饰替换槽。画布内圆角短粒导航的当前项宽度变为三倍，随深浅背景改变对比；柔角拨片约 22.67 CSS px，左上尖端为热点，移动带两颗约 160ms 消退的圆角短粒尾迹。

## 统一操作栏与逐页排版

从左到右：上一页／页码目录／下一页、编辑文字／替换素材、动效开关／下载 HTML／下载 PDF、带图标的全屏。全屏保持最右，不提供「纯文字」开关。

文字密度与装饰配图由 Agent 在生成阶段逐页处理，见 [content-layout.md](content-layout.md)。内部的 `.text-led` 是该页既定排版的一部分，下载 HTML 和 PDF 都应保留；不依赖全局模式、播放器按钮或 `body` 上的状态。

修改逐页排版支持时，验证同一份稿件可以混合文字页与配图页，隐藏装饰不会删除信息图表，保存 HTML 后离线重开及实际 PDF 的构图一致。播放器不会根据用户临时编辑后的字数自行隐藏图片或重排；新增内容应由 Agent 重新检查版面。

GROVE 的 24 张原创彩色植物线描 SVG 按 `seed`、`connect`、`nurture`、`flourish` 各六张，初始完整库不显示新增筛选。第 1、3、4、6、8、30 页默认配图，按 contain 保留深绿轮廓和本套填色；文字与插图短距离上移淡入，不持续摇摆、漂浮或随鼠标倾斜。第 5、7 页的二维时间分配和贡献柱形是信息图，不进入装饰替换槽。画布内导航由小种子形标记与当前页的宽叶片区分位置，浅底深绿、深底浅叶绿。叶尖鼠标主体约 22.67 CSS px，左上端为热点，移动带两片约 160ms 消退的短叶尾迹；操作界面、文字编辑、关闭动效、减少动态及触屏恢复系统鼠标。原站动态未完整实测，这些是 GROVE 自己的交互方案。


十二套当前中英文均各30页，信息布局范围第10–29页，原收尾位于30页。所有新增页共享有限图表入场及统一清理生命周期；表格、阶段时间与条件分支保留语义关系。示例原配图位置只改变收尾页码；每套24张素材不变。参见 [30页能力清单](layout-coverage.md)。
