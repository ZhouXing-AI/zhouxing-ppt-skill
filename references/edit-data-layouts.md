# EDIT 数据图表与四列布局

EDIT中英文样稿各30页：保留原前9页、第10–23页四列布局与数据图表；第24–29页增加六种业务版式，原收尾位于第30页。全部十二套均各30页，总计720页。数据是原创虚构样例，不来自外部调查或真实业务；制作真实演示时替换数据、口径、单位及结论。

新页面围绕选稿、编排、删改、校阅与刊发；全部数值是本地编写的示例，示例性质保留在本制作参考与 deck.json 的 data_provenance 中，不在成品画布显示制作标签。单位保留在图表坐标、图例或实义说明中。它们不来自网站、调查或真实编辑团队。新稿按用户资料重写数据、单位、结论和来源，不把示例数字用作外部证据。

## EDIT视觉边界

使用暖纸白 `#f2eee7`、亮纸白 `#fcf8f0`、酒红墨色 `#352129`、校改红 `#b64032`、浅红 `#e8a496`、纸灰 `#d8d1c9`。校样纸、细红线、括注和纸边应组织读数，不能划掉关键数值或盖住数据。第12、16、18、22、23页用酒红整底，在纸面与深底间建立节奏；目标清单是一张连续校样纸，不能拆成三个独立仪表卡。全宽图表、两区分栏和并列小图按内容分别选择，不把所有页面变成同一种卡片仪表盘。

英文主标题用 `EditSerif`，强调用真正的 `EditItalic`；中文主标题用 `EditCJK`真实300，深底用400。图内数轴和功能标签用 `ShiftSans,EditCJK` 400；关键大数字、系列名称及编辑式批注可用 `EditSerif`／`EditItalic`，中文对应 `EditCJK`，让数据延续书刊字体的笔画反差。保持本主题宋体中文字形，不换成其他主题黑体或点阵字。字体不新增、不裁样稿子集、不伪加粗斜体。

以1920×1080画布为基准，标题区左、右各120px，顶距82px；英文主标题默认104px、行高1.12，中文82px、行高1.2。说明与标题间距22px，英文说明28px、中文26px。图框默认左120px、上340px、大小1680×610；四张校样纸及目标清单从350px开始。标题连同说明的实际底边，与图表或卡片的上边至少相隔60px。新数据、两行标题和中文长标签必须实测边界后调整，不能通过缩小所有正文或挤占导航区域来硬塞内容。

除独立柱形的固定浅纸边，数据均按二维尺度绘制。柱形正面准确对应数量；透视、体积和装饰厚度不承担数据编码。曲线不平滑制造不存在的峰谷，面积从零开始；热力色段和雷达范围跨对象一致。

## 从工作副本复用

工作副本 `source/chart-recipes/` 包含标准库Python模块：`extras.py`返回卡片和目标进度，`bars.py`返回六种柱形/构成图，`analysis_charts.py`返回六种分析图。它们均有 `get_slides(lang)` 与 `validate_data()`。先修改配方中的数据、单位、文案与翻译，再执行验证；图表已经渲染为原生SVG，`data-chart-values`只是数据口径记录，不会驱动浏览器重算图形。

```sh
python3 scripts/render_edit_data_slides.py --project /absolute/path/to/deck --lang zh-CN --output /absolute/path/to/new-edit-data.html
```

脚本读取所给EDIT工作副本的配方，校验后按“卡片→六种柱形/构成图→六种分析图→目标”生成14个section，对应第10–23页。输出路径由调用者指定，文件存在即拒绝覆盖；不会改 `source/slides.html`、调用构建器或打开浏览器。输出依赖工作副本样式与播放器，是页面片段而非可独立打开的演示。

Agent按内容选择所需section放入 `source/slides.html`，调整页序，再运行 `build_deck.py`。新稿不要求固定页数或包含全部图表。图表样式保存在 `source/data-layouts.css`，并已拼入 `source/style.css` 和中文样式末尾；修改样式时同步保留。底部文字编辑不是图表数据编辑器，不能只改数字标签而留下旧几何。

所有数据图带 `data-information-visual`，不进入装饰替换槽。原装饰槽位于第1、3、5、8、30页；新增信息图不消耗或增加24张装饰素材。

## 图表进场与验收

标题、提示与说明用 `.reveal`；`data-chart-container` 容器只淡入，坐标系不整体位移。数据元素以 `data-chart-motion` 和非负 `data-chart-step` 指定有限时长的语义进场：柱条沿数轴展开，实线用 `draw` 绘制，虚线用 `wipe-x` 揭示且保留原 `stroke-dasharray`，面积从左揭示，桑基分层展开，散点逐个出现，热力按行显现。象形校样等 `pop` 元素使用 `transform-box:view-box`，变换中心用SVG坐标中的自身中心；不能使用 `fill-box` 再叠加同一组绝对坐标，否则图形会偏离原位置。最终路径、坐标、宽度、厚度和数值不由动画改写，静态SVG本身完整可见。

`source/chart-motion.js` 在播放器前内嵌，全部效果由播放器统一结束与取消。快速翻页、关闭动效、进入编辑或目录、保存HTML及下载PDF时应清理在途效果；系统减少动态默认静态。不能只看一张最终截图：实际播放并抽取开始、中段和结束帧，与关闭动效的终态对照，检查虚线语义、零基线、桑基十条流量、散点标签与全部热力单元。

PDF导出先结束动画，再仅在导出副本中冻结 SVG `text` 与 `tspan` 的计算字体样式，包括字体族、字号、字重、字形与字距。子级 `tspan` 的百分号字号等独立设置不能被父节点覆盖。这样离线栅格化仍保留衬线大数字和图表标签的实际外观；不改动原稿、配方或页面几何。

交付前检查两语言30页的字体、文字边界、标题与内容至少60px间距和数据比例；在动画中保存后离线重开，并实际下载30页PDF，核对衬线大数字、百分号、校样浅边、透明填色与静态终态完整。目标页的实际值、目标线和百分点差必须同时保留。预览、生成稿、下载HTML和PDF使用同一份内容，不为预览单独隐藏制作标签。PDF不含导航、鼠标、编辑提示或动画，为高清静态画面而非可选择文字层。其余播放器验收见 [player-contract.md](player-contract.md)。
