## 复用与边界

`source/expansion30.py` 是独立标准库Python模块，内含本主题配置、数据和SVG渲染函数。`get_slides('en')` 或 `get_slides('zh-CN')` 返回20个完整section；`validate_data()` 验证尺度边界、各组百分比、工时余额、桑基每层与节点守恒、散点与热力格数量等。它不读取 `data-chart-values` 去修改浏览器图形，也不依赖装饰素材库。

在工作副本运行以下命令生成一个**新片段文件**，然后由 Agent 按需要替换 `source/slides.html` 的对应section。已有输出文件会拒绝覆盖；不能直接把片段当成完整演示打开。

```sh
python3 source/expansion30.py --lang zh-CN --output /absolute/path/to/new-layouts.html
```

三个节点层的桑基总量为 `[40,35,25]` → `[60,40]` → `[65,35]`。第一段矩阵 `[[30,10],[20,15],[10,15]]`，第二段 `[[40,20],[25,15]]`，10条全部标值，单位4px/项；流带的透明叠色不编码额外数量。环形图不做透视，漏斗每层等高且宽度精确对应数量，不能把梯形面积误当人数。

排版在全宽图、并列列、左侧大字与图、数值表、流程和矩阵之间变化。四列卡片的文字如增长，先调整行长、字号和数量，不裁掉信息。比较表是维度行与方案列的矩阵；正文长时需要改行高和列宽，不能仅更换词语。

新增20页使用 `.expansion30` 命名空间，标题80px顶距、说明约200px、图框340px×1680×610。原页面CSS和插槽位置不被重排。单位、图例与条件属于信息内容；不为装饰添加数字旁注。

## 动画与验收

原生SVG为完整静态终态。`draw`只用于实线，虚线用`wipe-x`；柱条按轴展开，流带分阶段出现，等径点以view-box坐标保持中心。所有WAAPI对象交给播放器统一finish/cancel，不写持久隐藏样式。

验收包含中英新增页真实浏览器截图、文字边界与标题间距、数值验证、实际动画开始/中段/结束、快速翻页与关闭动效。保存HTML再离线打开，PDF使用同一份内容与已解析SVG字体，检查静态终态；底部文字编辑不是数据几何编辑器。
