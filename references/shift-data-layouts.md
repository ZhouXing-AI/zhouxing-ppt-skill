# SHIFT 数据图表与四列布局

SHIFT中英文样稿各30页：保留原前9页、第10–23页四列布局与数据图表；第24–29页增加六种业务版式，原收尾位于第30页。全部十二套均各30页，总计720页。数据是原创虚构样例，不来自外部调查或真实业务；制作真实演示时替换数据、口径、单位及结论。

画布只呈现面向观众的内容，不显示“示例数据”“四列卡片”等数据身份或版式制作标签。此类信息保留在制作资料或机器可读元数据中；单位、量尺、图例和必要的统计口径仍须可见，可写在图表标题、坐标轴或实义副标题中。预览、用户生成的演示及下载 HTML/PDF 使用同一套成品页面结构，不通过隐藏标签或预览专用样式制造不同版本。

## 选择与构图

- 图表页沿用前九页的点阵节奏、银色圆牌、铜橙焦点和日程细线，而不是给所有图套同一张“左图右 KPI”版式。一个页面先确立一个视觉重点，再安排比较、解释和背景参照；网格线退到次要层级。
- 第 11–23 页标题组在 1920×1080 画布的约 y=76 处起排，副标题紧随标题；分析图的独立副标题约 y=199。图表区通常从 y=330 开始，标题/副标题的实际下沿与图表区至少留 60px，不能只按固定坐标假设不会碰撞。中英文分别检查换行。第 10 页四列卡片保持自己已确认的构图。
- 不强制所有图表都配一个大数字侧栏。可选全宽比较、并列小图、四组点阵、主数值与趋势、平面圆盘与指标表、双阶段流向或三行进度。标题表达结论，单位、图例及范围随信息区域组织。
- 垂直柱形：比较少量类别；必须从零开始，保持同宽同尺度。本套前三柱为银色，末柱为铜橙焦点；材质只给正面投影添加固定深度与短椭圆顶，不使用透视坐标或体积编码。
- 水平柱形：类别名称较长、排名比较；长度编码数值，排序和标签对应。
- 象形柱图：用等面积金属圆片组成点阵单位，可按四个小组分区；写明每片所代表的数值，不以图标面积暗示长度。不能整片表达的数据需标注部分单位或改用普通柱图。
- 分组柱形：同一批类别在不同阶段的比较；可用三个并列小图，统一纵轴范围、零基线和图例，不能独立缩放来夸大差异。
- 百分比堆积：比较构成，逐组相加为 100%；不是绝对规模比较。显示数量时另用绝对值堆积。
- 瀑布：起点、增减和终点必须算得出，正负方向明确，浮动条的端点和连接线对应累计值。
- 折线、面积：按连续时间排序，直接标注单位与图例，不通过平滑曲线制造不存在的峰值。面积图从零开始。
- 雷达：所有维度使用同一标准化范围；轴顺序固定，不凭多边形面积宣称总体优劣。
- 桑基：内部节点入流与出流守恒，每层总量一致，连接厚度使用统一数量尺度；说明单位，显示节点总量和流量。本样稿的全部十条流带均标注人数。
- 散点：两个数值轴表示两个变量，不能把相关关系写成因果；类别或关键点可用直接标签。
- 热力：颜色映射统一范围，配图例与单元数值；不只依赖颜色区分。
- 四列卡片：四项并列信息使用同宽卡片和对齐输出行，不要求配图。
- 目标进度：沿用日程细线排成三行，大数字和差值在左，细进度条与目标标线在右。实际值与目标共用量尺；允许实际超目标，不截断数据来“完成”展示。差值单位是百分点。

二维优先服务读数。3D 仅用于少量独立柱形的浅挤出，不能改变数据长度、遮挡对象或作为本套所有图表的默认效果。折线、雷达、桑基、散点等保留二维。图形遵守银灰、铜橙、棕黑、纸白、少量金色，不引入新的主题色。

## 数据与复用

每个工作副本的 `source/chart-recipes/` 包含 `bars.py`、`analysis_charts.py`、`extras.py`，用固定示例数据和计算几何生成原生 SVG；不依赖网络或 JS 图表库。先阅读对应模块中的数据常量、单位和标签，按实际数据修改，重新检查所有合计、比例、轴范围、叙事结论及英文/中文翻译。

```sh
python3 scripts/render_shift_data_slides.py --project /absolute/path/to/deck --lang zh-CN --output /absolute/path/to/new-data-layouts.html
```

该命令按“四列卡片 → 六种柱形/构成图 → 六种分析图 → 目标进度”的顺序生成 14 个 section，对应样稿第 10–23 页；会执行模块提供的 `validate_data()`，输出文件已存在时拒绝覆盖。它只生成页面片段，使用工作副本中已有的 SHIFT 页面样式，不生成独立播放器。Agent 将需要的 section 放入 `source/slides.html`，按信息结构调序、删减和重排，再调用 `build_deck.py`。新稿不要求固定页数。单文件 HTML 中的图表是已渲染的 SVG；底部编辑功能修改普通文案，不是图表数据编辑器。改数值必须同时更新几何，不能只改标签。

图表标记 `data-information-visual`，不放进装饰素材替换槽。原 24 张装饰 SVG 与这 13 种数据图表是两类内容，替换装饰不应改变图表。标题、轴、图例和单位属于必要信息，导出 HTML/PDF 时全部保留。

## 图表进场

分析图的主标题与实义说明使用 `.reveal`；图表根容器标记 `data-chart-container`，只淡入，不随整段文字平移。数据元素使用 `data-chart-motion` 和非负整数 `data-chart-step`：实线轮廓用 `draw`，虚线和面积用 `wipe-x`，点用 `pop`，标签与热力单元用 `fade`。虚线不能用绘线效果覆盖原有间隔。桑基先显示来源与第一层流带，再显示中间节点与第二层流带，流带厚度始终来自最终数据。

这些标记只描述进场顺序，不改变数值、坐标、流量或最终比例；静态 SVG 本身必须完整可见。`pop` 的中心来自 SVG 的 `getBBox()`，应配合 `transform-box:view-box`，不可使用 `fill-box` 再叠加绝对坐标，否则圆片会在进场时漂移。`source/chart-motion.js` 由构建器在播放器前内嵌，效果交给播放器统一结束与清理。新增图表按 [播放器图表动效约定](player-contract.md#十二套图表动效) 检查真实时序、静态终态与导出，不以一张最终截图代替动画验收。

## 校验

中文使用既有 ShiftCJK 字库，英文/数字用 ShiftSans；点阵字仅用于支持的短英文或数字，不用来排汉字或小号数轴。至少检查全部中英文页面、轴标签与图例是否重叠、数据是否守恒、30 项导航是否在画布内，以及实际下载的 PDF（SVG 文字、填色、比例）。PDF 仍是高清静态页，不含可独立选择的矢量文字层。

SHIFT 的 PDF 导出器在离屏副本上固化 SVG `text/tspan` 的计算字体与文字绘制样式，再交给截图库；这是为了保留点阵数字和通过 CSS 定义的字号。不要删除这一处理或只检查 HTML 截图来推断 PDF 效果；原演示 DOM 和数据几何保持不变。

当前原前9页与收尾保留；第10–23页四列布局与图表经过 SHIFT 专属视觉优化，第24–29页包含独立数据表、方案对比矩阵、阶段时间轴、分支决策流程、环形占比和漏斗；原收尾移至30页。全Skill为12套、24份中英文演示、720页。当前以30页样稿及 [统一能力清单](layout-coverage.md) 为准。

新六页配方在 `source/expansion30.py`，以实际数据生成文字与几何。`validate_data()` 检查工时总量、占比总和、漏斗非递增与时间阶段闭合。示例为40工时、三类占比和同一批100个对象的逐级筛选；不能作为真实业务事实。表格中异质产出不合计；方案表按维度横向比较；流程的修改分支在对应判断条件复查后再前进。

版式CSS在 `source/expansion30.css`，并合并进style.css和locale-zh.css；普通创作仅改工作副本。调用 `scripts/render_layout_extensions.py` 输出片段再选择插入。新增图表采用原统一有限动画；24张装饰SVG、字体、前9页及原收尾保留。检查30页实际PDF、离线HTML、导航计数和字体终态。


## 本套图表的视觉细化与小图使用

- 标题区与数据区分别组织，实际文字下沿至数据区保留至少60px。铜橙只强调最新数据或关键结论；网格、对照数值与材料反光退到次要层级。第10页四列以银灰、纸白、铜橙、棕黑区分，并对齐卡片输出行。
- 第14页用点阵+20强化共同变化，第21页强调两个值得关注的散点但不增加新的变量；第22页使用方形金属格与点阵95%，第23页用点阵数字和细线进度呼应原第9页日程。颜色变化不能改变数值、分类阈值或量尺。
- 第24页用大点阵40工时与真正四列表格；第25页用三个圆牌表头和窄铜橙强调比较方案；第26页使用铜橙底的扁平周历；第27页以判断节点、动作和真实返回箭头说明决策；第28页让40工时居于环形中心；第29页以等厚金属条表达100→70→45→30，点阵30%归纳最终保留比例。不要把这些页换成通用白底仪表盘。
- 仅在第11、12、18、21、24、26、29页的合适留白区添加小幅装饰SVG。使用已有24张素材，不新增网络图片。标题右侧素材框约220–260px，侧栏素材框约230–280px（1920×1080画布），按素材的实际可见面积检查大小；一页最多一幅，离文字和数据保留约40–60px。不强制每张图表配图。
- 标题右侧素材出现时限制标题宽度并检查中英换行；侧栏素材不能挤压单位、主要数值和说明。小图置于信息SVG外，使用 `.sculpture.mini-chart-art.reveal` 或对应扩展页的小图类、`data-decoration="true"` 和独立 `data-artwork-slot`，让素材替换只影响装饰。
- 深色背景的小图由现有素材管理器把棕黑点阵映射为纸白点阵。保留原始24张资产的SVG数据、许可与默认恢复ID；下载HTML带上用户选择。小图只做有限淡入，不给数据页加持续旋转或鼠标倾斜。图表进场与终态不依赖装饰是否存在。
- 小图和新布局必须存在于工作副本源文件、注册样稿和实际导出中。`source/chart-refinement.css` 的规则已合并进 style.css 与 locale-zh.css；页面生成器的输出与样稿一致。检查素材替换后的HTML离线重开及真正下载的30页PDF。
