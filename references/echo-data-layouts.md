# ECHO · 回响：三十页样稿与数据布局

版本1.0.0。每种语言各30页；原前9页保持，20页扩展位于10–29，原结尾为30。所有数值由本地原创，用于表达概念而非外部事实，不来自参考网站、调查或真实活动。生成用户成品时替换为用户数据或已核实来源；单位、分母与限制保留在图中，制作属性保留在 `deck.json` 和此参考文档，不另做预览专用隐藏。

## 复用与排版

`source/expansion30.py` 为无外部依赖的标准库Python配方，`get_slides('en')`、`get_slides('zh')` 或 `get_slides('zh-CN')` 返回20个完整section，`validate_data()`检查范围、百分比合计、流量、目标差值和漏斗转化。可执行：

```sh
python3 source/expansion30.py --validate
python3 source/expansion30.py --lang zh-CN --output /absolute/path/to/new-fragment.html
```

输出已存在时拒绝覆盖。Agent选择所需section放入 `source/slides.html`，再构建；片段依赖同一工作副本的样式与播放器，不能独立打开。布局ID为 `echo-<kind>`。图形已在生成时按准确值绘制，`data-chart-values`只记录口径，不会驱动浏览器重算。需要改变数值时先改配方并验证，再重新生成几何。

专有样式 `.slide.x30` 与 `.x30-echo` 追加在 `source/style.css`，不会更改原9页和结尾；中文覆盖限定 `html:lang(zh) .slide.x30`。固定1920×1080，标题区左、右120px、顶80px；图文区左120px、顶350px、1680×610。标题连说明与正文的实测间距至少60px。标题过长时重写、换行或重新构图，不能压住数据或导航。装饰素材保持原24张且不把信息图纳入素材替换库；页面不必逐页配装饰图。

## 动效与导出

标题/说明 `.reveal` 继续使用本主题短入场；信息容器仅淡入。数据按轴展开，实线 `draw`、虚线 `wipe-x` 保留间隔；`pop` 使用 `transform-box:view-box` 和自身SVG坐标中心。全套动画都有限时长，由播放器统一finish与cancel；快速翻页、编辑、目录、关闭动效、保存和PDF必须显现完整最终图形，不遗留蒙版或内联隐藏。

PDF以最终画面离线栅格化，导出副本冻结SVG文字及tspan的计算字体族、字重、字号、字距、填色与描边，避免衬线大数或百分号样式丢失。导出副本必须保留section原有内联CSS变量；定位样式应追加或逐项赋值，不能用整段 `style.cssText=` 清空背景与文字颜色变量。PDF不是可编辑PPTX，也没有可选择文字层。交付检查中英30页的文字边界、至少60px标题间距、数值尺度、图例、30个画布内页点、实际中间动效及保存重开；实际PDF逐页核对背景、字体与完整终态。
