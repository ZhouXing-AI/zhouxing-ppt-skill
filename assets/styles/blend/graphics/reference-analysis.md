# BLEND · 融合 — Original artwork library

The single visual reference is Butter Video, https://www.butter.video/.
The official page was observed through the local screenshots
`output/theme-eleven-research-20261107/butter-1.png` and `butter-4.png`.
The parent project handles the complete website analysis.

This original library translates a playful creative-tool sensibility into
soft translucent modules. It does not use the source brand, keychains,
letters, application screenshots, or downloaded artwork.

The material uses purple #5D57F4, peach #FF986B, pale lilac #D7D0FC,
mint #C9E9DD, ink #17171A and paper #F4F3F0. Related light and dark
shades form rounded surfaces; thin upper-left highlights and short transparent
edge offsets add volume. Layered tint is intentional. There is no metallic
finish, black contour, hard industrial connector or large glow.

Twenty-four distinct silhouettes cover four categories, six in each:
collect / 收集; combine / 组合; shape / 塑形; release / 发布.

Core artwork IDs: soft-loop, split-prism, linked-petals, ribbon-fold,
feedback-dial, open-spark. All 24 belong to the first release of this theme;
the catalog contains no added-version or new-asset marker.

Each SVG is a transparent 1000 × 1000 vector document using local paths and
gradients. There are no fonts, visible text, bitmap images, scripts, external
references, or filters. All illustrations are original and MIT licensed.
