# BLEND · 融合：Butter Video 单站拆解

记录日期：2026-11-07。本套唯一网站视觉参考为 [Butter Video](https://www.butter.video/)，由用户 Eagle 收藏选出。参考提供设计观察；BLEND 的内容、配色角色、页面构图和 SVG 均独立设计。

## 网站在做什么

Butter 是在线的视频编辑工具。官网围绕时间线组织剪辑，并以可组合、可调整的工具块和模板扩展创作过程，覆盖导入、编辑、增强和输出。其工具块可以复用并调整参数，也展示通过描述和代码参与创作的方式。因此，本套提取的是“清楚的工具框架承托有表现力的内容”，而不是将视频产品界面伪装成演示。依据：[Butter 官方首页](https://www.butter.video/)。

## 五条可转译的设计原则

1. **中性画布让物件承担色彩。** 背景与正文维持稳定的灰白/黑对比，少数明亮半透明部件成为视觉锚点。BLEND 不把每一个文字框都涂成彩色，也不让炫光影响正文。
2. **几何字形靠比例建立层级。** 标题大、行数少，正文使用正常字距和较稳定的行宽。保留轻巧清晰的工具感；中文独立控制断句，不横向压缩来追赶英文宽度。
3. **圆角是功能语法。** 小按钮、短索引与控制件柔和，主体构图仍由清楚的对齐线组织。可以有圆润卡片，但不把十页都变为相同的仪表盘卡格。
4. **时间线转成组合过程。** 从“多个工具块沿时间线工作”的产品逻辑，转成演示中的收集、连接、试验、成形。细轨道、阶段标记、并列片段承载关系；不复刻真实编辑器、播放头或原站控件布局。
5. **物件表达用途，动效解释进入顺序。** 原创 SVG 以透明片、软边模块、连接结构和层叠关系说明创意组合。演示采用短距离进入、轻微淡入与依次显现；这属于适配决策，截图不能证明原站具体时长。物件停止后保持稳定，PDF 和减少动态模式保留完整清晰构图。

## BLEND 的原创方向

主题名为 **BLEND · 融合**，内部 ID `blend`，内容方向为创意组合方法：让不同线索形成联系，通过试验组织成可用成果。网站是视频编辑器，演示不是其产品介绍，不能沿用其商业主张或将样片写成 Butter 官方材料。

本套适配色板如下，**并非原站逐色采样或逐色复刻**：

| 颜色 | 在本套中的职责 |
|---|---|
| `#F4F3F0` | 温和灰白画布与主要留白 |
| `#17171A` | 正文、结构线与必要深底 |
| `#5D57F4` | 紫色主强调、当前状态与核心连接 |
| `#FF986B` | 蜜桃色辅助片与局部对照 |
| `#D7D0FC` | 淡紫透明叠层 |
| `#C9E9DD` | 浅薄荷层与辅助组合关系 |

SVG 使用原创圆润组合物件与半透明艳色层次。避免原站钥匙串、钥匙、挂扣组合、品牌挂件、Butter 字样、客户 Logo、应用图标、工具缩略图及其真实纹理；不导入原站摄影、视频、音频、WebGL 场景或任何品牌资产。封面采用独立的信息位置和物件结构，不复刻“顶置钥匙串＋中央一行标题＋按钮”的首屏布局。正文、流程和样例数据另写，原网站文案不作为 PPT 内容。

## 可嵌入的开源字体

使用 Google Fonts 官方固定提交 `24ddc1f324cac5d9f5aedca126d298f56e3f1640` 的完整源字体，替代原站字体；没有打包 DieGrotesk 或 ABCDiatype。

| 用途 | 家族与 CSS 别名 | 真实字重/覆盖 |
|---|---|---|
| 英文标题、正文、界面 | Space Grotesk / `BlendSans` | 完整变量 TTF，范围 300–700；本套用 400/500/600，735 个 Unicode 码点 |
| 小型英文索引与数字 | DM Mono / `BlendMono` | 完整 Regular TTF，真实 400，381 个码点 |
| 中文标题、正文、界面 | Noto Sans SC / `BlendCJK` | 完整变量 WOFF2，范围 100–900；标题 500，正文 400，30,890 个码点 |

三套字体均为 SIL OFL 1.1，允许依条款商业使用、嵌入和随软件再分发；完整版权和许可随包保留，字体本身仍使用 OFL。三套 `fsType=0`，正体、真实字重，不合成粗斜体。Space Grotesk 与 DM Mono 保留官方 TTF 原字节；中文复用已核验的完整 Noto 无损 WOFF2，重新比对了官方 TTF 的 cmap、字形清单和内部名称，没有按样稿裁字。

完整覆盖不意味着所有 Unicode 或任意扩展汉字均受支持。实际文案仍须通过 coverage 检查，`BlendMono` 不用于排中文。来源、文件大小、SHA、真实轴范围和保留字体名要求记录在 [fonts/font-manifest.json](deck/fonts/font-manifest.json)、[NOTICE.txt](deck/fonts/NOTICE.txt) 与各 `*-coverage.json`；构建配置为 `fonts-en.json` 和 `fonts-zh-additions.json`。

官方来源：[Space Grotesk 固定版本](https://github.com/google/fonts/tree/24ddc1f324cac5d9f5aedca126d298f56e3f1640/ofl/spacegrotesk)、[DM Mono 固定版本](https://github.com/google/fonts/tree/24ddc1f324cac5d9f5aedca126d298f56e3f1640/ofl/dmmono)、[Noto Sans SC 固定版本](https://github.com/google/fonts/tree/24ddc1f324cac5d9f5aedca126d298f56e3f1640/ofl/notosanssc)。
