Complete official variable font binaries were downloaded, then losslessly
compressed to WOFF2 using fontTools 4.60.2 and Brotli 1.2.1.
All preprocessing transforms were disabled. Every decompressed SFNT table
is byte-identical to its source, with only the container-dependent
head.checkSumAdjustment and WOFF2 lossless-transform flag (head.flags bit 11)
excluded from byte comparison. No subsetting,
outline editing, glyph renaming, naming edits or variable-axis changes were
performed. This retains the full repertoire of the official SC sources,
not the complete Unicode or pan-CJK repertoire. Audit: font-audit-zh.json.

Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
See the complete NotoSansSC-OFL.txt. The Reserved Font Name 'Source' is not
used as the primary family name. Internal Noto font names are preserved.
Variable wght 100–900 (source default 100); choose 400 for body and UI
text, 900 for the artwork-picker UI heading. Slide h1/h2 headlines now
use Glow Sans SC Compressed ExtraBold 800 (IndexCJKDisplay); see
GlowSansCompressed-NOTICE.txt. These are real weights, not fake bold.

request explicit weights because both source variable fonts default to
