INDEX FONT BUNDLE — SOURCES AND LICENSE NOTICE

The Latin TTF font binaries in this folder are unmodified copies from the
official Google Fonts repository. Local filenames and CSS aliases were
changed for integration only; original internal font names and notices
remain intact. Chinese body and serif fonts are complete official Noto
fonts after a lossless container conversion; see NOTICE-zh.txt and
font-audit-zh.json. Chinese display headings use the complete official
Glow Sans SC Compressed ExtraBold v0.93 font, compressed to WOFF2; see
GlowSansCompressed-NOTICE.txt, GlowSansCompressed-OFL.txt and
font-audit-condensed.json. Each family retains its full OFL license.

Distribution notes:
Keep this notice, NOTICE-zh.txt and all five complete OFL files with redistributed fonts.
Font software retains OFL-1.1. The OFL does not require the slide content to
use the same license. Do not sell these font files by themselves.
IBM Plex Mono carries the Reserved Font Name "Plex"; its binaries are unmodified.

CSS aliases: IndexDisplay, IndexSerif, IndexMono.
Use Anton at weight 400. Newsreader files contain wght 200–800 and opsz 6–72;
the intended tab-label weight is 400. IBM Plex Mono files are 400 and 500.
Use the separate Newsreader italic file for italic labels.

This bundle does not include Founders Grotesk or Signifier.
