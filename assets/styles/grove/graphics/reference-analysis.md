# GROVE · 共生 — Original botanical artwork

The single website reference chosen and observed by the parent project is
Therapy in London, from the user's Eagle collection (MSTZVMU2MCS12).
These new illustrations translate the provided direction of warm paper,
green/lilac color and informal botanical ink. The parent project owns the
official site observation and complete visual analysis.

The library uses paper #F2EFDF, dark green ink #253A31, green #4CA785,
lilac #B6A2D3, pale leaf #B8D7B8 and blue #6385D4. Filled silhouettes,
irregular curves, leaf veins and sparse line hatching carry the form. There
is no 3D modeling, glass material, gradient, photorealistic shadow or glow.

All silhouettes are original. No source-site flowerpots, lamps, hands,
people, brand elements or downloaded illustrations are included. Four
categories contain six distinct compositions each: seed / 播种, connect /
联结, nurture / 培育, flourish / 共生. The initial catalog has no added-version
flags.

Each SVG is transparent 1000 × 1000. There are no fonts, visible text,
bitmaps, scripts, filters, gradients or external references. SVG strokes
are typically 4–6 units; a few main stems are wider to preserve structure
at presentation size. Ink-heavy illustrations are designed for paper,
light lilac or pale green surfaces. The dark preview explicitly shows a
paper mount on a dark canvas; it does not add a background to the assets.

The illustrations and catalog are MIT licensed.
