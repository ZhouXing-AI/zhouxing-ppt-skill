## 首屏中可确认的视觉语言

### 1. 温暖浅底，而非医疗科技蓝

首屏大部分是带灰的暖奶油色；深绿近黑承担文字和线描轮廓。绿色叶片、紫色灯具、蓝色小卡片提供少量鲜明颜色，浅底仍保持连续。

Eagle 自带聚类统计记录：RGB(234,234,226) 约82%，RGB(60,77,64) 约5%，RGB(61,132,239) 约5%，RGB(15,190,117) 约1.26%。这是缩略图像素聚类，**不是官网 CSS 色板或各元素精确色值**。紫色可在灯具和标题下划线中目视确认，但该聚类摘要没有单列可靠的紫色色值。

### 2. 轻柔的大无衬线标题

首屏标题很大，但不是黑体超粗或窄体压缩。它通过两行、紧凑但不拥挤的行距，以及足够留白建立中心。正文用较小的常规无衬线，字重对比温和。

GROVE 采用自己的 Onest 400/500 英文字形；中文选寒蝉半圆体真实 Regular 400。圆角轮廓带来亲和力，内容层级主要靠字号、位置、行距和色彩，而不通过假粗体或横向挤压实现。

### 3. 彩色线描具有手工感

首屏植物和室内物件采用可辨认的轮廓、略有变化的曲线、少量平涂。它们不是高光树脂、金属或精细写实3D。深色线条统一了不同填色，形体仍然清楚。

GROVE 抽取“轮廓 + 色块 + 自然曲线”这一语言，用原创植物关系图表达生长、交换和互相支持。每个素材需要独立绘制，保留自己的枝叶拓扑、比例和负空间。

### 4. 图像包围信息，内容依然是中心

原首屏图像分布在中央标题两侧和下方，中心文案保持连续。GROVE 不复刻“左盆栽 + 右台灯 + 下方蓝卡”的具体构图；改用左右分栏、上文下图、单物件局部放大和少图留白等页面形式。

### 5. 连接与成长是可迁移的抽象主题

官网文本强调专业人员与客户之间的连接、建立实践与参与社区。GROVE 只借鉴这种友善、支持性的叙事气质，重新写成一般团队与社区协作方法，不提供心理治疗建议，不引用原站服务承诺、费用、资格要求或原文标题。

## 字体包与许可结论

完整记录位于 `deck/fonts/font-manifest.json`、每个 `*-coverage.json` 及 `NOTICE.txt`。

- **Onest 2.001**：官方完整变量 TTF，780个 Unicode 码点，876 glyphs，wght100–900；本套用400/500。来源为固定 Google Fonts commit `24ddc1f324cac5d9f5aedca126d298f56e3f1640`，保留官方 OFL 与 METADATA。
- **DM Mono Regular**：完整官方 TTF，真实400，用于小型数字与索引；同一固定 Google Fonts commit，保留 OFL 与 METADATA。
- **寒蝉半圆体 ChillRoundM v1.805**：作者 [Warren2060/ChillRound](https://github.com/Warren2060/ChillRound/releases/tag/v1.805) 的完整原始 OTF，真实400，12,329个 Unicode 码点、12,779 glyphs；实测完整覆盖 GB2312 的6,763汉字。固定标签指向 `46dda1602729b58de96e3fdee9f918d7aaa64727`，保留 release/tag JSON、README 和完整 OFL。
- 源泉圆体官方当前 OTF 目录只有JP/PJP/TC/TW，没有已验证的SC版；因此没有把台湾字形版本标成SC，也没有沿用普通 Noto Sans 作为本套中文字体。
- 三个字体均为 OFL1.1、fsType0，并以官方原字节嵌入。字体可按 OFL 条件商用、嵌入及随开源 Skill 再分发，许可独立于 SVG/代码许可。完整字库指完整保留原发行字库，不承诺全部 Unicode。
- CSS别名为 `GroveSans`、`GroveMono`、`GroveCJK`；内部原字体名称未改。中文不合成500/700；设置 `font-synthesis:none`。
