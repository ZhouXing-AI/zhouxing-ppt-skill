The manifest contains fixed URLs, source/delivery SHA256, release archive
member and archive hash, actual weights/axes, cmap coverage, glyph counts,
font-name checks, license/metadata hashes and embedding permission bits.
Original official OFL and METADATA files are bundled. For Smiley, official
release JSON and tag-resolution JSON serve as source/release evidence.

Barlow and Manrope keep unmodified official TTF bytes. Smiley keeps the
exact official SmileySans-Oblique.ttf.woff2 release bytes, also matched
byte-for-byte to the cached official ZIP member. Its filename is shortened
locally, but no font table, glyph, name, metric or permission bit changed.
The CSS alias does not change the font's internal family or Reserved Font
Names. Noto reuses the complete previously audited WOFF2; its original
lossless conversion disabled preprocessing transforms. No repeat
conversion, subsetting, outline or internal-name edits were performed.

Complete official source repertoire verified:
- Barlow Condensed ExtraBold: 525 Unicode cmap codepoints, true weight 800.
- Manrope: 678 Unicode cmap codepoints, real variable weight 200–800.
- Smiley Sans: 9,440 Unicode cmap codepoints, true weight 400.
- Noto Sans SC: 30,890 Unicode cmap codepoints, real variable weight 100–900.

Smiley's internal post.italicAngle is -8 degrees and fsSelection marks
the actual face italic. Declare both its @font-face and Chinese display
text as font-style:italic; this selects its real native oblique design.
Do not add skew(), scaleX(), synthetic bold, or a second slant. Use
font-synthesis:none throughout. The font is visually heavy but has genuine
weight 400: requesting 800 would not create a real heavier master.

Smiley's unmodified fsType is 0x0008 (Editable Embedding), which permits
editable document embedding; it is not Restricted License Embedding.
The official OFL separately permits commercial use and redistribution.
The other three fonts have fsType 0 (Installable Embedding). These values
were inspected and preserved, not patched. OpenType permission reference:
https://learn.microsoft.com/en-us/typography/opentype/spec/os2#fstype

All cmap sets, glyph counts and internal font-name tables were compared
with the complete official source TTF files. Full source coverage does
not claim all Unicode or all pan-CJK characters. Noto Sans remains the
readable body face; Smiley is reserved for display text. Original large
Noto TTF and Smiley ZIP/TTF stay in the development cache; pinned URLs and
hashes can restore them. They are not runtime dependencies.
