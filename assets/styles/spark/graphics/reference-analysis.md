# SPARK · 燃点 — original resin action modules

Single visual reference: [Anyflow Labs](https://labs.anyflow.agency/), observed in the official-site captures `output/theme-ten-research-20261107/anyflow-1.png` through `anyflow-6.png`.

The reference contributes fluorescent green against black and near-white, large direct typography, and a short-extrusion object language. SPARK translates these relationships into an original library about starting, shaping, testing and advancing. It does not reuse the site's sculpted letter logo, honeycomb, hexagonal elements, imagery or lettering.

The material is solid fluorescent resin: lime `#B7FF3C` faces, pale-lime `#E7FF9A` highlights, deep-green `#396214` sidewalls and limited charcoal `#11140F` connectors. Gradients stay inside this green family to describe volume. A short 17–32 px extrusion and a restrained face highlight give the objects a tactile industrial-toy character. There are no ice-blue glass surfaces, silver-black metal, image textures or glow filters.

The 24 original objects have distinct outlines and purposes, six per category:

- **start / 启动**: rocker switch, idea capsule, pull tab, trigger puck, solid idea bulb and elastic starter.
- **shape / 塑形**: three-way joint, folded panel, snap frame, turning elbow, hinged surfaces and shaped wave.
- **test / 试验**: return loop, gauge window, balance support, trial wheel, split route and sample probe.
- **advance / 推进**: rising blocks, momentum arrow, launch ramp, relay baton, expanding gates and directional sail.

The six core narrative objects are `ignition-switch`, `idea-capsule`, `modular-joint`, `test-loop`, `step-blocks` and `momentum-arrow`.

Each SVG uses a transparent 1000×1000 canvas. There are no visible text elements, fonts, embedded bitmaps, remote resources, scripts or filters. `catalog.json` contains English/Chinese names, keywords and descriptions; this is the first complete 24-object library and has no `added_version` or “new” flags.
