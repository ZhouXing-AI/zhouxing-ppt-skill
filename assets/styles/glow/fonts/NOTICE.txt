The manifest records each fixed official URL, source and delivered SHA256,
byte length, true weights/axes, complete Unicode coverage, embedded license
metadata and license hash. The original source TTF files can be restored
from these URLs; source cache paths are not runtime dependencies.

DM Serif Display retains unmodified official TTF bytes. Poppins reuses the
complete, previously verified WOFF2 files from SKETCH (compression only).
Noto reuses the complete, previously verified FOCUS/INDEX WOFF2 bytes,
with no repeat conversion. The latter used lossless TTF-to-WOFF2
compression with all preprocessing transforms disabled. Internal names,
outlines, metrics, variable axes, hints, copyrights and licenses remain.
Only local filenames and CSS aliases differ. No font is subset to slide
copy. Full SC-source coverage does not mean all Unicode/pan-CJK coverage.

Coverage verified against complete official source files:
- DM Serif Display Regular: 333 Unicode codepoints.
- DM Serif Display Italic: 336 Unicode codepoints.
- Poppins Regular/Medium: 471 Unicode codepoints each.
- Noto Serif SC: 30,928 Unicode codepoints, real weight axis 200–900.
- Noto Sans SC: 30,890 Unicode codepoints, real weight axis 100–900.

Use font-synthesis:none. DM Serif Display is a true 400-only family; do
not request synthetic 600/700. Italic emphasis uses the real italic file.
Chinese display uses 900 and body/UI uses 400. Do not artificially skew
or horizontally distort Chinese glyphs.
